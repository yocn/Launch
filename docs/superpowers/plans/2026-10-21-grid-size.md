# 行列数设置 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 外观设置可调列数（4～10）与行数（3～8），主网格、文件夹、拖动、键盘、布局编辑都按新行列工作。

**Architecture:** 新增 `GridSize` 值类型，由 `LauncherSettings` 持久化；`LauncherHomeLayout` 持有 `grid` 并据此计算缩放系数、行距与列距；`LauncherModel` 与 `LayoutCoordinator` 的每页容量改为可更新；`LaunchApp.applySettings` 同步设置。默认 7×5 时所有尺寸与现状一致。

**Tech Stack:** Swift 6，SwiftUI，AppKit，XCTest。

**Spec:** `docs/superpowers/specs/2026-10-21-grid-size-design.md`

命令：`swift build 2>&1 | grep -E "error:|warning:|Build complete"`；`swift test 2>&1 | grep -E "error:|with [1-9][0-9]* failures|Executed [0-9]+ tests" | awk '/Executed/{print $2} /error|with [1-9]/{print}' | sort -n | uniq | tail -3`；安装 `LAUNCH_SIGN_IDENTITY="Apple Development: zhaoyingkun@163.com" ./scripts/build-app.sh --install`。

### Task 1: GridSize 与设置

**Files:** Create `Sources/LaunchApp/GridSize.swift`；Modify `Sources/LaunchApp/LauncherSettings.swift`；Test `Tests/LaunchAppTests/GridSizeTests.swift`、`Tests/LaunchAppTests/LauncherSettingsTests.swift`

- [ ] 失败测试：`GridSize(columns: 12, rows: 1)` 钳制为 10×3；`.default` 为 7×5、容量 35；设置默认 `grid == .default`，改 `gridColumns = 5`、`gridRows = 4` 后同一存储域新建实例读回 5×4。
- [ ] 实现：

```swift
struct GridSize: Equatable, Sendable {
    static let `default` = GridSize(columns: 7, rows: 5)
    static let columnRange = 4 ... 10
    static let rowRange = 3 ... 8

    let columns: Int
    let rows: Int

    init(columns: Int, rows: Int) {
        self.columns = min(max(columns, Self.columnRange.lowerBound), Self.columnRange.upperBound)
        self.rows = min(max(rows, Self.rowRange.lowerBound), Self.rowRange.upperBound)
    }

    var capacity: Int { columns * rows }
}
```

`LauncherSettings`：`gridColumns`、`gridRows`（Int，didSet 写入，键 `gridColumns`/`gridRows`，缺省取 `GridSize.default`），`var grid: GridSize { GridSize(columns: gridColumns, rows: gridRows) }`。
- [ ] 测试通过后提交：`feat(设置): 行列数设置项`

### Task 2: LauncherHomeLayout 按行列计算尺寸

**Files:** Modify `Sources/LaunchApp/LauncherHomeLayout.swift`；Test `Tests/LaunchAppTests/LauncherHomeLayoutTests.swift`

- [ ] 失败测试：
  - 默认 7×5：`iconSide == 88`、`tileHeight == 141`、`rowSpacing == 17`、`gridHeight == 773`（与现状一致）。
  - 5×3：`iconSide == 88`，`rowSpacing == (773 - 141 * 3) / 2`，列距均分。
  - 10×8：`fitScale < 1`，网格高度不变，`columnSpacing >= 17 * sizeScale`。
  - 所有屏幕 × {4×3, 7×5, 10×8} 网格放得下、列距为正。
  - 文件夹：行数上限为 `grid.rows`，列数为 `grid.columns`，行距为 `17 * sizeScale * fitScale`。
- [ ] 实现：`init(screenSize:referenceSize:grid: GridSize = .default)`；`static let baseGridHeight: CGFloat = 141 * 5 + 17 * 4`；

```swift
// 放不下时整体缩小格子；列间距不小于默认行距
fitScale = min(
    1,
    Self.baseGridHeight / (141 * rows + 17 * (rows - 1)),
    availableWidth / (112 * columns + 17 * (columns - 1))
)
```

其中 `availableWidth = contentSize.width * (1 - 0.18) / sizeScale`。格子类尺寸（`iconSide`、`tileWidth`、`tilePadding`、`iconLabelSpacing`、`labelFontSize`、`labelHeight`、`tileCornerRadius`）乘 `fitScale`；`gridHeight = baseGridHeight * sizeScale`；`rowSpacing = (gridHeight - tileHeight * rows) / (rows - 1)`；`folderRowSpacing = 17 * sizeScale * fitScale`；`columnSpacing` 用 `grid.columns`；`folderRowCount` 用 `grid.columns`/`grid.rows`；`folderGridHeight` 用 `folderRowSpacing`。删去静态 `columnCount`/`rowCount`/`pageCapacity`。
