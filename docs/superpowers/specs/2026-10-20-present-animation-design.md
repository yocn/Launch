# 启动器唤起与隐藏动画 设计

日期：2026-10-20。状态：设计已确认，待编写实施计划。

## 1. 目标

参照 LaunchOS 录屏，为启动器的唤起与隐藏加入动画：背景渐显渐隐，内容（搜索框、网格、页码点、文件夹）缩放并淡入淡出。

## 2. 参考依据

LaunchOS 录屏（2026-10-20 19.26.22，3 次唤起/隐藏）逐帧测量：

- 唤起约 0.22 秒：以 App Store 图标为例，左边缘 258 → 297 像素（3024 宽录屏），按到屏幕中心的距离推算内容从约 1.03～1.04 倍收到 1 倍，减速曲线；图标很快淡入；背景（桌面）逐渐模糊、变暗，持续约 0.24 秒。
- 隐藏约 0.2 秒：内容从 1 倍放大到约 1.04 倍并淡出，约 0.15 秒消失；背景随后约 0.1 秒内退去。
- 背景本身不缩放（桌面文件位置不变）。

## 3. 交互规则

- 唤起：面板以透明状态出现；背景 0.25 秒减速淡入；内容 0.25 秒从 1.04 倍减速收到 1 倍，同时 0.15 秒内淡入。
- 隐藏：内容 0.16 秒放大到 1.04 倍并淡出，背景 0.22 秒淡出；动画结束后再收起面板；需要切回之前的应用时也在动画结束后进行。
- 所有关闭方式（快捷键、Esc、点空白、启动应用、切到别的应用、打开设置）都用同一套隐藏动画。
- 隐藏动画中再次唤起：从当前状态反向，取消原定的收起。
- 隐藏动画期间面板不响应鼠标。
- 系统开启「减弱动态效果」时只淡入淡出，不缩放。

## 4. 组件

| 组件 | 位置 | 职责 |
| --- | --- | --- |
| `PresentationTransition` | LaunchApp（新增） | 动画参数（隐藏时内容缩放 1.04、唤起/隐藏时长与曲线） |
| `DelayedDismissal` | LaunchApp（新增） | 延迟执行收起，可取消（代号机制），延时调度可注入 |
| `LauncherModel` | 扩展 | `isPresented` 与 `setPresented(_:)` |
| `LauncherController` | 扩展 | 唤起后置 `isPresented = true`；隐藏前置 `false` |
| `ScreenPresenter` | 扩展 | 收起延迟到动画结束；动画中 `isVisible` 视为已关闭；唤起时取消待收起；隐藏期间忽略鼠标 |
| `LauncherView` | 扩展 | 背景按 `isPresented` 淡入淡出；内容缩放与淡入淡出，减弱动态效果时不缩放 |

## 5. 测试与验证

- `DelayedDismissal`：到时执行、取消后不执行、重新开始只执行最后一次。
- `LauncherController`：唤起后 `isPresented` 为真、隐藏后为假；隐藏动画中再次唤起会重新唤起。
- 回归第 4b/4c/5a 期 e2e（关闭后检查面板的等待时间均长于隐藏动画）。
- 观感：用户录屏，按同样方法逐帧测量缩放比例与时长，与 LaunchOS 对比后微调参数。
