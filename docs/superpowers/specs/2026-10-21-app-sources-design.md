# 第 5d-2 期：应用来源目录 设计

日期：2026-10-21。状态：设计已确认。前置：`2026-10-21-layout-backup-design.md`（5d-1）。

## 1. 目标

设置「应用」页列出扫描应用的目录：默认目录固定，可添加、移除自定义目录；目录变化后立即重新扫描。

### 不在本期

停用默认目录；「Apple 应用位置」（排序相关）。

## 2. 参考依据

LaunchOS「应用来源」：目录列表，默认目录标「默认路径」，自定义目录可「移除」，用添加按钮选目录。

## 3. 交互规则

- 「应用」页最上方「应用来源」：
  - 每行显示文件夹图标与路径（家目录显示为 ~）。默认的 4 个目录（/Applications、/System/Applications、/System/Library/CoreServices/Applications、~/Applications）标「默认路径」，不能移除。
  - 自定义目录带「移除」按钮；目录不存在时标「不存在」，仍保留。
  - 「添加目录…」：选择一个或多个文件夹；已在列表中或位于已有目录之下的（子文件夹本来就会扫描）跳过，并在下方提示被跳过的目录。
  - 说明文字：子文件夹一并扫描。
- 目录变化立即保存并重新扫描、重新监听变化。
- 移除目录后其中的应用按未安装处理：保留在布局中的位置但不显示；再加回来就回到原处。新发现的应用排在最后。
- 同一应用出现在多个目录时按包标识只算一个（沿用现有去重）。

## 4. 组件

| 组件 | 位置 | 职责 |
| --- | --- | --- |
| `ApplicationSources` | LaunchApp（扩展） | 默认目录加自定义目录；添加时去重与跳过子目录 |
| `LauncherSettings` | 扩展 | 持久化自定义目录 |
| `SettingsView` | 扩展 | 「应用来源」列表、添加与移除 |
| `LaunchApp` | 扩展 | 目录变化时换新的目录监听器；丢弃旧监听器迟到的扫描结果 |

## 5. 测试与验证

- `ApplicationSources`：默认加自定义的顺序与去重；添加时跳过重复、默认目录与已有目录的子目录，规范化路径。
- `LauncherSettings`：自定义目录默认空、持久化。
- 目标机 e2e：把一个只含测试应用（复制系统里的小应用到临时目录）的临时目录加为来源，打开启动器能搜到它；移除后搜不到；布局文件中它的位置保留；删除临时目录。只跑相关 e2e。备份并还原布局与设置。
