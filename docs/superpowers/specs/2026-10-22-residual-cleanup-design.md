# 保守的卸载关联文件清理

日期：2026-10-22。用户已确认清单选择、安全边界与实现授权。

## 范围与交互

沿用 × 和右键卸载入口。后台只读扫描后显示应用本体及关联文件清单：路径、大小、用途、匹配依据、禁止选择的原因。仅应用本体默认勾选；残留均默认不选；本体不可取消，取消对话框则没有文件移动。运行中应用明确说明先正常退出，退出失败终止。

第一版只检查当前用户 Library 下 Caches、Logs、Preferences、Saved Application State、Application Support、Containers 中按完整 Bundle ID 命名的固定项；应用显示名/包名匹配的支持目录仅展示为不确定项。Group Containers 仅根据签名 entitlement 中声明的精确组名展示，始终禁止选择。不清理钥匙串、文稿、系统服务、扩展或系统级 Library，不增加提权或完全磁盘访问授权流程，不实现孤立残留全盘扫描。

## 强制规则

- Bundle ID 严格验证，拒绝路径分隔、点段和系统保留标识；签名须有效、签名标识与 Info.plist 一致、有 Team ID 且满足 Apple 签名信任要求。签名缺失或不匹配不影响仅卸载本体，但禁止清理其残留。
- 重新枚举默认及用户配置的应用来源，保留重复安装信息（不可复用会去重的 AppCatalog）；检查出错或达到限额视为不完整，残留禁止选择。已知其他安装副本同 ID 时禁止选择。
- Containers 还须核对容器元数据的所属标识。共享组、名称猜测和无法核对的数据只显示原因。
- 固定白名单的直接子项；从用户根目录起拒绝符号链接祖先；目录内容不跟随链接，发现符号链接、跨卷、硬链接或无法读取内容时整项禁选。扫描有数量/时间限额，不能完成则明确不完整，不把失败当没有残留。
- 固定扫描计划，不接受清单以外的 URL。记录设备号/inode/类型及目录内容元数据摘要；移动前重验路径、身份、内容、签名、重复安装。变化则跳过，退出产生的文件变化也一样跳过，允许用户重新扫描。
- 同一时刻只允许一个卸载流程。本体移动失败则停止；残留部分失败逐项报告，不尝试永久删除或强制退出。
- 开始移动前原子写入独立 JSON 操作记录，逐项移动前记为处理中、成功后记入实际废纸篓路径；记录失败则停止后续移动。崩溃期间的处理中项不冒充失败或成功。
- 使用系统废纸篓接口，不清空废纸篓；完成后提供记录文件的访达入口，记录指导从废纸篓恢复。不承诺运行状态或偏好设置完整恢复。

## 组件与验证

`ResidualScanner`：后台扫描、证据与快照、执行前复核。`UninstallCleanup`：固定计划执行、注入废纸篓操作、原子操作记录。`UninstallReview`：AppKit 清单与逐项选择。`UninstallCoordinator`：扫描、确认、退出、本体移动和结果展示；保留现有无清理流程的测试适配。

测试仅使用临时目录与假应用，废纸篓接口注入为临时目录内移动；覆盖默认未选、取消、不可信标识/签名、重复安装、共享组、越界/链接/硬链接、文件替换、内容变化、退出失败、本体失败、部分成功、日志保存失败。不卸载任何真实应用。实际 UI 验证只查看/取消清单，或使用临时假应用与注入预览。

局限：签名与精确 ID 不能证明其他未知进程绝不使用该目录；检查范围仅为配置的应用来源。路径复核与系统 trashItem 调用不是原子的，不能抵御同一用户恶意进程的精确竞态；不宣称 100% 安全。安全疑问按禁选处理。
