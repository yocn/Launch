# 显示屏、回到第一页与 Option 卸载模式 设计

日期：2026-10-21。状态：设计已确认。前置：`2026-10-20-settings-window-design.md`（5a）。

## 1. 目标

设置「通用」页加入三项：启动器显示在哪块屏幕；隔多久回到第一页；按住 Option 进入卸载模式。

### 不在本期

程序坞显隐：启动器窗口层级 25 高于程序坞（20），现已盖住程序坞与菜单栏，保持不变。显示程序坞图标。

## 2. 参考依据

LaunchOS：「启动台显示在」鼠标所在屏幕 / 当前激活屏幕 / Dock 所在屏幕 / 主屏幕；「回到主页面」从不 / 5 秒后 / 15 秒后 / 30 秒后 / 1 分钟后 / 5 分钟后 / 始终；「按住 Option 进入卸载模式」。本机程序坞窗口层级 20，位于内置屏。

## 3. 交互规则

### 3.1 显示在

- 选项：鼠标所在屏幕（默认，现状）/ 当前激活屏幕 / 程序坞所在屏幕 / 主屏幕。
- 当前激活屏幕：系统认定的主屏幕（有键盘焦点的窗口或活跃菜单栏所在屏幕）。
- 程序坞所在屏幕：程序坞窗口所在的屏幕；找不到时按鼠标所在屏幕。
- 主屏幕：系统设置中带菜单栏的那块。
- 找不到目标屏幕时都退回鼠标所在屏幕，再退回第一块屏幕。

### 3.2 回到第一页

- 选项：从不 / 5 秒后 / 15 秒后 / 30 秒后 / 1 分钟后 / 5 分钟后 / 始终；替换原「重新打开时」两项，原「停在上次的位置」对应从不、「回到第一页」对应始终，已保存的选择自动迁移。
- 打开时距上次关闭达到所选时长就回到第一页，否则停在原页；首次打开在第一页。

### 3.3 按住 Option 进入卸载模式

- 开关，默认开。
- 启动器打开、可编辑布局时（搜索框为空、自定义排序、未在改名）单独按下 Option 进入抖动模式，松开退出。
- 打开启动器时 Option 若仍按着（如 ⌥Space 唤起），要先松开再按才生效。
- 长按进入的抖动模式不因松开 Option 退出；Option 与其他修饰键同按不触发。

## 4. 组件

| 组件 | 位置 | 职责 |
| --- | --- | --- |
| `LauncherScreenChoice`、`ScreenSelectionPolicy` | LaunchApp（扩展） | 按选项选屏 |
| `ScreenPresenter` | 扩展 | 读取当前选项、程序坞与激活屏幕位置 |
| `ReturnToFirstPage` | LaunchApp（新增） | 七个选项与时长；从旧设置迁移 |
| `LauncherSettings` | 扩展 | 显示屏、回到第一页、Option 卸载开关 |
| `LauncherModel` | 扩展 | 记录关闭时刻，打开时按时长决定是否回第一页（时间可注入） |
| `OptionHoldTracker` | LaunchApp（新增） | 判断 Option 单独按下与松开，忽略唤起时仍按着的 Option |
| `LauncherInputMonitor` / `LaunchApp` | 扩展 | 监听修饰键变化，进入或退出抖动 |
| `SettingsView` | 扩展 | 通用页三项 |

## 5. 测试与验证

- `ScreenSelectionPolicy`：四种选项、程序坞与激活屏幕缺失时的退回。
- `ReturnToFirstPage`：时长、旧设置迁移；`LauncherModel`：未到时长停在原页、到时长回第一页、始终与从不。
- `OptionHoldTracker`：单独按下与松开、唤起时按着需先松开、与其他修饰键同按不触发、松开时只结束自己开始的抖动。
- `LauncherSettings`：默认值与持久化。
- 目标机 e2e：主屏幕与程序坞所在屏幕选项下鼠标在外接屏时唤起到内置屏；回到第一页选 5 秒，翻到第 2 页关闭后 2 秒内重开停在第 2 页、6 秒后重开回到第 1 页；按住 Option 出现抖动与 ×、松开消失、关闭开关后不再抖动。回归各期 e2e。备份并还原布局与设置。
