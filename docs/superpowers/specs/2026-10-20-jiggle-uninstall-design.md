# 抖动模式与卸载 设计

日期：2026-10-20。状态：设计已确认，待编写实施计划。前置：`2026-10-20-drag-edit-design.md`（第 4a 期）。

## 1. 目标

长按图标进入类似 Launchpad 的抖动模式：图标摇摆，可直接移到废纸篓的应用显示 ×，点 × 确认后把应用移到废纸篓。

### 不在本次

按住 ⌥ 进入抖动（与 ⌥Space 唤起冲突，需另行设计延迟）；需要管理员权限的应用卸载；清理应用的缓存与偏好设置；多选批量卸载。

## 2. 参考依据

- LaunchOS 二进制符号（只读）：抖动即卸载模式（`isUninstallMode`、`didTriggerUninstallLongPress`、`launchos.uninstall.jiggle.rotation/bounce`、`uninstallButton.bouncy.scale`），卸载窗口列出关联文件并移到废纸篓，运行中的应用先提示退出，需要时请求完全磁盘访问或管理员权限。
- 本机应用归属：`/System/Applications` 46 个（受保护）；`/Applications` 17 个归当前用户、6 个归 root 且需管理员（Xcode、Outlook 等）、Safari 受系统保护；`~/Applications` 6 个归当前用户。用户选择只为能直接删除的应用显示 ×。

## 3. 交互规则

### 3.1 进入与退出

- 在图标上按住 0.5s 且未移动超过 4pt 进入抖动；按下后先移动则按原逻辑拖拽。长按后不松手继续拖动，仍可拖拽图标。
- 只有能编辑布局时（未搜索、布局可写、不在改名）才能进入。
- 退出：点空白处（不关闭启动器）、Esc、搜索框输入文字、启动器关闭后再打开。
- Esc 层次：取消改名 → 关闭文件夹 → 退出抖动 → 清空搜索 → 关闭启动器。
- 抖动时点击应用与 Return 都不启动应用；点文件夹照常打开；拖拽、合并、改名照常可用。

### 3.2 外观

- 主网格与打开的文件夹中的图标以 ±2° 左右摇摆，每个图标周期略有差异，避免整齐划一。
- 可卸载的应用在图标左上角显示 × 圆形按钮，进入抖动时缩放弹出。

### 3.3 可卸载的判定

同时满足：位于 `/Applications` 或 `~/Applications` 之下；不在 `/System` 下；应用包本身不是符号链接；当前用户对应用包及其所在目录都有写权限；不是 Launch 自身。文件夹不显示 ×。

### 3.4 卸载流程

- 点 × 弹出确认：「要将“X”移到废纸篓吗？」，说明「可以在废纸篓中恢复。」，按钮「移到废纸篓」「取消」。
- 应用正在运行时，标题改为「“X”正在运行」，说明「退出后移到废纸篓，可以在废纸篓中恢复。」，按钮「退出并移到废纸篓」「取消」；确认后请求正常退出，最多等 5 秒，未退出则提示失败且不移动，不强制结束。
- 只把应用包移到废纸篓；成功后立即触发目录重新扫描，图标随之消失；布局保留该应用的位置（沿用未安装应用的规则），重新安装后回到原处。
- 失败时提示原因。确认框与错误提示的窗口层级高于启动器面板。
- 卸载后保持抖动模式。

## 4. 组件

| 组件 | 位置 | 职责 |
| --- | --- | --- |
| `AppUninstaller` | LaunchApp | 判定可卸载、查询是否运行、请求退出、移到废纸篓；文件系统、运行中应用与废纸篓操作均可注入 |
| `UninstallCoordinator` | LaunchApp | 确认 → （必要时退出）→ 移到废纸篓 → 重新扫描；失败提示 |
| `UninstallPrompting` / `AlertUninstallPrompter` | LaunchApp | 确认框与错误提示，窗口层级高于面板 |
| `LauncherModel` | 扩展 | `isJiggling`、进入/退出、Esc 层次、× 命中、`canUninstall` 注入 |
| `LauncherController` | 扩展 | 抖动时不启动应用；点空白先退出抖动 |
| `ItemDragController` | 扩展 | 长按计时；× 的按下与松开 |
| `LauncherView` | 扩展 | 摇摆动画与 × 按钮 |
| `CatalogWatcher` | 修改 | `rescan()` 可供外部调用 |

## 5. 测试与验证

自动化（XCTest）：

- `AppUninstallerTests`：在临时目录构造假应用包，覆盖可卸载判定的各条规则（含无写权限目录、符号链接、自身、目录外、`/System`），运行状态查询，退出等待超时，移到废纸篓调用注入的废纸篓操作（不触碰真实废纸篓）。
- `UninstallCoordinatorTests`：取消不删除；运行中且退出失败时报错不删除；成功时删除并重新扫描；删除抛错时报错。
- `LauncherModel` / `LauncherController`：进入条件、Esc 层次、搜索退出、重新显示退出、点空白退出、抖动时不启动、× 命中只在抖动且可卸载时成立。

目标机验证：

- 长按进入抖动、点空白/Esc 退出；抖动时点应用不启动；可卸载应用显示 ×，系统应用与 root 应用不显示。
- 只对测试时放入 `~/Applications` 的自制假应用执行卸载，确认确认框在面板之上、移到废纸篓后图标消失；验证后从废纸篓清理该假应用。不对任何真实应用执行卸载。
