# 第 5b-3 期：按类型分组 设计

日期：2026-10-21。状态：设计已确认。前置：`2026-10-21-arrange-layout-design.md`（5b-1 整理布局）。

## 1. 目标

「整理布局…」对话框加入规则「按类型分组」：把范围内散落的应用按 App Store 类别归入文件夹。

## 2. 参考依据

- LaunchOS：整理规则含按类型；类别中文名（效率、实用工具、开发者工具、社交、游戏、图形与设计、财务、教育、健康与健身、生活、医疗、音乐、新闻、摄影、参考、体育、旅行、视频、天气、美食佳饮、商务、娱乐、图书）；「新文件夹已放置在最后」。
- 本机 107 个应用中 80 个在 Info.plist 带 `LSApplicationCategoryType`；没有的多为 Apple 自带应用（计算器、时钟、天气、家庭、股市等）与少数第三方应用。

## 3. 交互规则

- 对话框规则：填满空位 / 取消所有分组 / 按类型分组，可同时勾选；执行顺序为取消分组 → 按类型分组 → 填满空位。整个整理一次 ⌘Z 撤销。
- 只处理范围内页面上散落的可见应用；隐藏与未安装的应用、已有文件夹及其成员不动。
- 类别：取应用 Info.plist 的 `LSApplicationCategoryType`（游戏的各子类都算「游戏」）；没有标记的 Apple 自带应用按内置表补上（天气→天气，家庭→生活，股市→财务，播客→娱乐，电话→社交，DVD 播放程序→视频，其余系统工具→实用工具）。仍没有类别的应用留在原处。
- 布局中已有同名文件夹（不限范围）时，该类应用并入那个文件夹末尾；否则该类至少 2 个应用才新建文件夹，只有 1 个的留在原处。
- 新文件夹按名称（拼音）排序，放在范围内最后一页的末尾；放不下的拆成紧随其后的新页（同时勾选填满空位时一起重排）。
- 名称完全相同才算同名（如「社交」不并入「社交网络」）。

## 4. 组件

| 组件 | 位置 | 职责 |
| --- | --- | --- |
| `CatalogApp.category` | LaunchCore（扩展） | 扫描时读取类别标识 |
| `AppCategory` | LaunchCore（新增） | 类别标识与 Apple 自带应用到中文名 |
| `LayoutArrangement.groupsByCategory` / `LayoutEditor` | LaunchCore（扩展） | 分组规则 |
| `ArrangeOptions` / `ArrangeLayoutDialog` | LaunchApp（扩展） | 新规则勾选框与校验 |

## 5. 测试与验证

- `AppCategory`：标识映射、游戏子类、Apple 表、未知返回空。
- `AppCatalog`：扫描读出类别。
- `LayoutEditor`：新建文件夹（至少 2 个、按名称排序、放在范围末尾）；并入已有同名文件夹（含范围外）；单个与无类别留原处；隐藏应用不动；与取消分组、填满空位组合；无变化返回原文档。
- `ArrangeOptions`：只勾选按类型分组时单页也可执行。
- 目标机 e2e：全部页面按类型分组后出现预期文件夹（如「实用工具」「开发者工具」）、「效率」文件夹成员增加、⌘Z 复原。只跑本期 e2e。备份并还原布局与设置。
