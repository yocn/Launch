# 第 5c-2 期：窗口模式 设计

日期：2026-10-21。状态：设计已确认。前置：`2026-10-21-scroll-browsing-design.md`（5c-1）。

## 1. 目标

显示方式可选「全屏」（现状，默认）或「窗口」：窗口模式下启动器显示为屏幕中央的圆角玻璃窗口。

## 2. 参考依据

LaunchOS「显示模式」：经典的全屏 Launchpad 体验 / 现代化窗口体验。

## 3. 交互规则

- 入口：主菜单「显示方式 ▸ 全屏 / 窗口」，立即生效并保存。
- 窗口：屏幕宽 70%、高 75% 以内，按参考屏比例取内容区大小，居中；圆角、淡边框与柔和投影；不能拖动或缩放。
- 背景：玻璃材质、模糊壁纸、系统壁纸与暗度照旧，只显示在窗口内；窗口外透明，不压暗。
- 关闭：点窗口外或窗口内空白处、切到别的应用、Esc 等与全屏相同；打开时屏幕上的菜单栏与程序坞点到也只是关闭启动器。
- 网格行列、图标与文字按窗口大小整体缩放；分页、滚动、文件夹、拖动、多选、右键都在窗口内照常工作；唤起与隐藏动画相同。

## 4. 组件

| 组件 | 位置 | 职责 |
| --- | --- | --- |
| `DisplayMode` / `LauncherSettings` | LaunchApp | 全屏、窗口，持久化 |
| `LauncherHomeLayout.windowArea` | 扩展 | 窗口占屏幕的范围 |
| `ItemMenu` / `LauncherModel` / `LaunchApp` | 扩展 | 主菜单子菜单与设置同步 |
| `LauncherView` | 扩展 | 按窗口范围计算布局，背景只留圆角区域，窗口外点击按空白处理 |

## 5. 测试与验证

- 设置默认值与持久化；主菜单子菜单打勾与命令；窗口范围尺寸。
- 目标机 e2e：切到窗口后图标都在中央区域且内容不变；点窗口外关闭、重开仍为窗口；窗口里拖动、⌘Z、右键；切回全屏。只跑本期 e2e。备份并还原布局与设置。
