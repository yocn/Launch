# 第 4b 期：多选与批量操作 设计

日期：2026-10-20。状态：设计已确认，待编写实施计划。前置：`2026-10-20-drag-edit-design.md`（4a）、`2026-10-20-jiggle-uninstall-design.md`。

## 1. 目标

在主网格中按住 ⌘ 点选或框选多个应用与文件夹，把它们一起拖动，或通过右键菜单合并到新文件夹、合并到选中的文件夹、移动到指定页。

### 不在本期

单项右键菜单与隐藏应用（4c）；文件夹内多选；⌘A 全选；批量卸载；新文件夹位置设置。

## 2. 参考依据

- LaunchOS 中文本地化与二进制符号（只读）：「按住 ⌘ 键的同时，鼠标点选或框选，选中多个应用或文件夹，然后整体排序、移动、隐藏」；`SelectionMarqueeView`、`selectionMarqueeInitialGroupIDs`、`LaunchpadMultiDrag`（「同时拖拽多个选中的应用」）；多选菜单 `MultiSelectionAppMenu` 含「已选中 %d 个项目」「合并到新文件夹」「合并到“%@”」「移动到 → 第 %d 页」「隐藏」。
- 参考应用试用已过期，无法实际操作；选中外观、拖动预览等细节按常见惯例确定（用户确认）。

## 3. 交互规则

### 3.1 选择

- ⌘ + 单击应用或文件夹：切换其选中状态，不启动、不打开。
- ⌘ + 拖动（从空白或图标上开始均可）：拉出选框，选框相交的图标加入选择，按下前已选中的保持选中；只作用于当前页，不自动翻页。按住 ⌘ 时不翻页、不拖走图标。
- 选择在翻页后保留，可在多页间累积。
- 只在主网格多选；打开的文件夹内 ⌘ + 单击按普通单击处理。进入条件与拖拽相同：未搜索、布局可写、不在改名。抖动模式下也可多选，× 仍只卸载对应的单个应用。
- 外观：选中项背后显示比键盘选中更亮的底板，图标右上角显示蓝色对勾；选框为半透明白色圆角矩形加细边框。
- 清空选择：普通单击任意图标（只清空，不启动、不打开）、单击空白（不关闭启动器）、Return（只清空）、搜索框输入文字、启动器关闭、完成一次批量操作；目录或布局变化后去掉已不存在的项。
- Esc 层次：取消改名 → 关闭文件夹 → 清空选择 → 退出抖动 → 清空搜索 → 关闭启动器。
- 点空白层次：关闭文件夹 → 清空选择 → 退出抖动 → 关闭启动器。

### 3.2 一起拖动

- 不按 ⌘ 拖动已选中的图标：所有选中项一起拿起。拖动未选中的图标：先清空选择，再按 4a 逻辑只拖这一个。
- 拖拽图像为按住的图标，带选中数量角标。
- 拿起后所有选中项从网格消失、其余图标补位；插入位置空出与选中数量相同的格子，超出本页容量的部分在预览中不显示。
- 停在应用中心约 0.1s 出现文件夹底板，放下后在目标位置新建「未命名」文件夹，成员为目标在前、选中项在后。
- 停在文件夹上：选中项并入该文件夹末尾。
- 合并时选中项按页序（页、行、列）排列；其中的文件夹拆开，成员（含未安装应用）按原顺序并入，原文件夹消失。插入时文件夹保持原样。
- 插入：选中项按页序连续排在插入位置，满页挤到下一页；边缘翻页、临时空白页、Esc 或面板外松开取消，与单项拖拽相同。
- 放下后各选中项从松手位置落到各自目标格；整个操作为一步 ⌘Z。

### 3.3 多选菜单

- 右键或 Control + 单击已选中的图标弹出菜单；在未选中的图标或空白处右键本期不响应。
- 菜单项：
  - 「已选中 N 个项目」：灰色标题，不可点。
  - 「合并到新文件夹」：选中至少 2 项时可用；新文件夹「未命名」放在页序最靠前的选中项的位置。
  - 「合并到“X”」：选中项中每个文件夹各一项，选中至少 2 项时出现；其余选中项并入 X 末尾。
  - 「移动到」子菜单：「第 1 页」…「第 N 页」「新页面」；选中项按页序追加到该页末尾，满页挤到下一页。
- 合并时选中的其他文件夹按 3.2 规则拆开并入。
- 每个菜单操作为一步 ⌘Z，执行后清空选择。

## 4. 组件

| 组件 | 位置 | 职责 |
| --- | --- | --- |
| `LayoutEditor` | LaunchCore | 新增 `moveGroup([LayoutItemID], to: LayoutDropTarget)` 与 `mergeIntoNewFolder([LayoutItemID])`，规则见第 5 节 |
| `MultiSelection` | LaunchApp（新增） | 选中集合：切换、选框（初始选择 ∪ 相交项）、按页序排序、过滤失效项 |
| `GridHitTester` | 扩展 | 返回与给定矩形相交的格子 |
| `DragSession` / `DragPreview` | 扩展 | 被拖项改为一组（按住项 + 其余）；预览中各页去掉被拖项、插入处空出 N 格；含文件夹的组可合并 |
| `SelectionMenu` | LaunchApp（新增） | 按模型给出的菜单内容（数量、能否新建文件夹、可选文件夹、页数）生成 `NSMenu` 并回调 |
| `LauncherModel` | 扩展 | 持有选择与选框矩形；清空时机与 Esc 层次；菜单命令转为 `LayoutEdit` 交给 `onEdit` 后清空选择 |
| `ItemDragController` | 扩展 | ⌘ 单击、⌘ 拖动选框；拖已选中项时发起一组拖拽；右键与 Control + 单击弹出菜单 |
| `LauncherController` | 扩展 | 点空白分层；有选择时 Return 只清空 |
| `LauncherView` | 扩展 | 选中底板与对勾、选框、多项落位动画 |

- 数据流与 4a 相同：鼠标监听 → `LauncherModel` → `onEdit(LayoutEdit)` → `LayoutCoordinator.apply` → `LayoutEditor` → 保存发布。
- macOS 26 上本地监听拦不住 SwiftUI 手势：模型记录 ⌘ 按下状态，SwiftUI 的翻页拖动与点空白回调据此忽略。
- 菜单用 AppKit `NSMenu` 从监听中弹出，不用 SwiftUI `.contextMenu`。

## 5. `LayoutEditor` 规则

- `moveGroup(项列表, 到目标)`：
  - 项列表按调用方给出的顺序（页序）处理，按身份定位，找不到的项忽略。
  - `insert(可见页, 在某项之前 / 页末)`：目标页在移除前按可见页定位；移除所有组内项后在锚点处连续插入，锚点不在目标页或为空时追加到页末；随后连锁挤页。锚点不能是组内项。
  - `newPage`：组内项依次放入新建的末页，超出容量连锁挤页。
  - `merge(应用)`：该应用替换为新文件夹（`folder-<UUID>`、「未命名」），成员为目标 + 组内应用；`merge(文件夹)`：组内应用追加到其末尾。组内文件夹拆开，成员按原顺序并入；目标本身在组内时从组中排除；目标不存在时原样返回。
- `mergeIntoNewFolder(项列表)`：至少 2 项；第一项的位置换成新文件夹「未命名」，成员为全部组内项拆开后的应用；其余项移除。
- 沿用 4a：编辑涉及的页去掉 `.empty`、空页删除、首次编辑拆分超量旧页、结果不变时原样返回（调用方据此跳过保存与撤销）。

## 6. 测试与验证

自动化（XCTest）：

- `LayoutEditorTests`：组插入（同页、跨页、锚点前、页末）、连锁挤页、新页面超量、合并到应用（位置、成员顺序、名字）、合并到文件夹、拆开选中的文件夹（含未安装成员）、目标在组内、`mergeIntoNewFolder` 的位置与成员、少于 2 项无效、无变化原样返回。
- `MultiSelection`：切换、选框并集与收缩、页序排序、过滤失效项。
- `GridHitTester`：矩形相交。
- `DragPreview` / `DragSession`：多项预览排列、跨页隐藏、含文件夹的组可合并。
- `LauncherModel` / `LauncherController`：进入条件、清空时机、Esc 与点空白层次、Return 只清空、菜单内容与命令转换、⌘ 按下时忽略翻页与点空白。
