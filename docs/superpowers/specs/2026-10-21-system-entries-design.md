# 第 5e 期：触发角、F4 键与触控板捏合 设计

日期：2026-10-21。状态：设计已确认。前置：`2026-10-21-display-behavior-design.md`（通用设置）。

## 1. 目标

新增三种唤起方式：鼠标移到屏幕角（触发角）、按 F4 键、触控板捏合。

## 2. 参考依据

- LaunchOS：触发角（左上、右上、左下、右下，「与系统触发角设置冲突」）用全局鼠标监听；「系统 F4 键」用按键事件拦截、「触控板」三指捏合 / 四指或五指捏合 / 五指捏合用手势事件拦截，两者需要辅助功能权限。
- 本机：MacBook Pro（Mac16,8，M4 Pro）内置键盘，F4 键为 Spotlight，未开启「将 F 键用作标准功能键」；系统触发角右下角为快速备忘录；LaunchOS 正在运行，其触发角设置为 4（推测为右下角）；系统「拇指加三指捏合」已开启。

## 3. 交互规则

### 3.1 触发角（不需要权限）

- 通用页「触发角」：关（默认）/ 左上角 / 右上角 / 左下角 / 右下角。
- 指针碰到任一屏幕的所选角时切换启动器（关着就打开，开着就关闭）；离开该角后才能再次触发。
- 所选角已被系统触发角占用时提示「与系统触发角冲突」；LaunchOS 正在运行且其触发角可能是同一角时提示「可能与 LaunchOS 的触发角冲突」。只读取系统与 LaunchOS 的设置，不修改。

### 3.2 F4 键与触控板捏合（需要辅助功能权限）

- 通用页「系统 F4 键」开关（默认关）与「触控板」选项：关（默认）/ 三指捏合 / 四指或五指捏合 / 五指捏合。
- 任一项打开而 Launch 没有辅助功能权限时，显示「需要在系统设置中允许 Launch 使用辅助功能」与「打开系统设置」按钮；授权由用户在系统设置中完成，Launch 每 2 秒检查一次，授权后自动生效。
- F4：按下 F4 键切换启动器，按键被 Launch 接管、不再执行原功能（本机为 Spotlight，仍可用 ⌘空格）。识别的键：F4（按住 fn 或开启标准功能键时）、旧键盘的启动台键、新键盘 F4 位置上的功能键；实际键码在用户授权后按键核对。
- 捏合：所选手指数在触控板上向内捏合时打开启动器（已打开时关闭），该次手势被 Launch 接管。四指或五指与系统「拇指加三指捏合」冲突时，在选项下方说明可能同时触发系统手势。
- 为核对键码与手势，拦截时只记录特殊键（F 键、启动台、Spotlight 等）的键码与捏合手指数，不记录字母、数字等普通按键。

## 4. 组件

| 组件 | 位置 | 职责 |
| --- | --- | --- |
| `HotCorner` / `HotCornerDetector` | LaunchApp（新增） | 角的判定与「离开后才能再次触发」 |
| `HotCornerConflicts` | LaunchApp（新增） | 读取系统与 LaunchOS 的触发角设置判断冲突 |
| `HotCornerMonitor` | LaunchApp（新增） | 全局与本地鼠标移动监听 |
| `PinchRecognizer` | LaunchApp（新增） | 按触点帧判断 N 指向内捏合 |
| `SystemInputTap` | LaunchApp（新增） | 辅助功能权限检查、事件拦截（按键与手势）、失效后重新启用 |
| `LauncherSettings` / `SettingsView` / `LaunchApp` | 扩展 | 设置项、通用页与接线 |

## 5. 测试与验证

- `HotCornerDetector`：各角与多屏判定、离开后再触发；`HotCornerConflicts`：系统值与 LaunchOS 值映射。
- `PinchRecognizer`：N 指向内捏合识别、手指数不符或张开不识别。
- 设置默认值与持久化。
- 目标机 e2e：选左下角后把指针移到内置屏左下角打开启动器、再碰一次关闭，选「关」后不再触发；冲突提示文字。F4 与捏合由用户授权后按键与做手势，结合日志核对。备份并还原设置。
