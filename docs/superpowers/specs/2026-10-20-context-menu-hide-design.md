# 第 4c 期：右键菜单与隐藏应用 设计

日期：2026-10-20。状态：设计已确认，待编写实施计划。前置：`2026-10-20-drag-edit-design.md`（4a）、`2026-10-20-jiggle-uninstall-design.md`、`2026-10-20-multi-select-design.md`（4b）。

## 1. 目标

右键单个应用或文件夹弹出菜单（打开、在访达中显示、显示简介、隐藏、移到废纸篓；文件夹为打开、重命名、取消分组、隐藏）；可以隐藏应用，并在菜单栏中查看和取消隐藏。

### 不在本期

空白处右键主菜单、设置窗口、「在搜索结果中显示隐藏应用」开关（第 5 期）；更换图标；卸载时清理关联文件。

## 2. 参考依据

- LaunchOS 中文本地化与二进制符号（只读）：单项菜单 `AppMenu` 含「打开」「在访达中显示」「显示简介」「隐藏」「卸载」；文件夹有「重命名」「取消分组」（「解散后的应用会添加到原页面末尾。若该页面已满，将依次放入下一页」）；「右键点击应用即可隐藏」；设置中有「隐藏的应用」列表与「取消隐藏」、「在搜索结果中显示隐藏应用」开关；「右键任意空白位置打开主菜单」。
- 架构文档：隐藏状态属于用户布局，导出再导入应保留。

## 3. 交互规则

### 3.1 右键菜单

- 右键或 Control + 单击图标弹出菜单；主网格、打开的文件夹、搜索结果、抖动模式中均可用；空白处右键本期不响应。
- 右键已选中的图标仍弹出多选菜单；右键未选中的图标先清空选择，再弹出该图标自己的菜单。
- 应用菜单：
  - 「打开」：同单击，抖动时不可用。
  - 「在访达中显示」。
  - 「显示简介」：让访达打开该应用的简介窗口；首次使用时系统询问是否允许 Launch 控制访达，被拒绝时提示到「系统设置 → 隐私与安全性 → 自动化」开启。
  - 「隐藏」。
  - 「移到废纸篓…」：只对可直接删除的应用显示，沿用抖动模式的确认与卸载流程。
- 文件夹菜单：
  - 「打开」。
  - 「重命名」：打开文件夹并进入标题编辑。
  - 「取消分组」：成员按原顺序添加到文件夹所在页末尾，满页挤到下一页，文件夹消失。
  - 「隐藏」：隐藏全部成员。
- 多选菜单在「移动到」之后新增「隐藏」，作用于全部选中项（文件夹按全部成员处理）。
- 隐藏、取消分组为布局编辑，各为一步 ⌘Z；布局只读或改名中时这些项不可用。

### 3.2 隐藏

- 按应用记录，保存在 `layout.json`。
- 隐藏的应用从网格、文件夹和搜索结果中消失；原位置保留但不显示、不占格子，规则同未安装应用；文件夹成员全部隐藏时文件夹不显示。
- 菜单栏菜单新增「隐藏的应用 ▸」：按名称列出已安装且被隐藏的应用，点一项取消隐藏；末尾「全部取消隐藏」；没有时该项为灰色。取消隐藏的应用回到原位置，各为一步 ⌘Z。
- 重新安装被隐藏的应用仍为隐藏；从 Launchpad 重新导入布局时保留隐藏列表；从备份恢复时随备份文件。

## 4. 组件

| 组件 | 位置 | 职责 |
| --- | --- | --- |
| `LayoutDocument` | LaunchCore | 新增 `hiddenApps: [AppIdentity]`；缺少该字段的旧文件按空列表读取，格式版本不变 |
| `LayoutEngine` | LaunchCore | 解析时跳过隐藏应用；隐藏应用计为已放置，不追加到末尾；`ReconciledLayout` 给出已安装的隐藏应用 |
| `LayoutEditor` | LaunchCore | 隐藏应用按未安装处理；新增 `hide([LayoutItemID])`、`unhide([AppIdentity])`、`ungroupFolder(String)`，规则见第 5 节 |
| `LayoutCoordinator` | LaunchApp | 发布布局时一并发布隐藏应用；提供取消隐藏与全部取消隐藏；重新导入时保留隐藏列表 |
| `ItemMenu` | LaunchApp（由 `SelectionMenu` 扩展） | 按多选、应用、文件夹三种内容生成 `NSMenu` 并回调命令 |
| `LauncherModel` | 扩展 | 按位置给出菜单内容；布局类命令转为 `LayoutEdit`；搜索排除隐藏应用 |
| `AppActions` | LaunchApp（新增） | 在访达中显示（`NSWorkspace`）、显示简介（`NSAppleScript` 控制访达，未授权时提示） |
| `ItemDragController` | 扩展 | 右键与 ⌃ 单击向模型索取菜单内容；系统类命令交给外部回调 |
| `StatusItemController` | 扩展 | 菜单打开时生成「隐藏的应用 ▸」子菜单 |
| `scripts/build-app.sh` | 修改 | Info.plist 增加 `NSAppleEventsUsageDescription` |

- 布局类命令（隐藏、取消分组、多选各项）：模型 → `onEdit` → `LayoutCoordinator.apply` → 保存发布。
- 系统类命令（打开、在访达中显示、显示简介、移到废纸篓）：交给 `AppActions` 与 `UninstallCoordinator`，不改布局。
- 菜单栏取消隐藏直接调用 `LayoutCoordinator`，同样进入撤销栈。

## 5. `LayoutEditor` 规则

- 隐藏应用：`itemID` 为空，不计入容量，不能作为插入锚点或合并目标；文件夹只有未隐藏且已安装的成员时才可见。
- `hide(项列表)`：应用加入隐藏列表，文件夹的全部成员（含未安装）加入隐藏列表；已隐藏的不重复加入；位置不变。
- `unhide(身份列表)`：从隐藏列表移除（按 Bundle ID 或路径匹配）；位置不变，所在页可见项超过容量时按首次编辑规则拆分。
- `ungroupFolder(文件夹)`：文件夹移除，成员（含未安装与隐藏）按原顺序追加到该页末尾，随后连锁挤页。
- 沿用 4a：涉及的页去掉 `.empty`、空页删除、结果不变时原样返回。

## 6. 测试与验证

自动化（XCTest）：

- `LayoutEditorTests`：隐藏应用与文件夹、隐藏应用不占容量且不可作锚点、取消隐藏回到原位、取消分组的顺序与挤页、无变化原样返回。
- `LayoutEngineTests`：隐藏应用不显示、不追加，成员全隐藏的文件夹不显示，`ReconciledLayout` 给出隐藏应用。
- `LayoutStoreTests`：没有 `hiddenApps` 的旧文件能读取，保存后保留隐藏列表。
- `LayoutCoordinatorTests`：取消隐藏与全部取消隐藏、重新导入后保留隐藏列表。
- `ItemMenu`：三种菜单的项、可用状态与命令。
- `LauncherModel`：按位置给出的菜单内容（应用、文件夹、多选、未选中项清空选择）、命令转换、搜索排除隐藏应用。

目标机验证：

- CGEvent 端到端：右键应用与文件夹的菜单内容；隐藏后图标消失、菜单栏列表出现、取消隐藏回到原位；取消分组；⌘Z；在访达中显示后关闭打开的访达窗口。
- e2e 前备份用户的 `layout.json` 与 `layout.json.backup`，结束后还原并比对哈希。
- 显示简介涉及系统授权，由用户手动验证。
- 完成后同步 README、架构文档与 `docs/manual-verification.md`。
