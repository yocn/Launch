# 第 5c-1 期：滚动浏览 设计

日期：2026-10-21。状态：设计已确认。前置：`2026-10-21-grid-size-design.md`（行列数）、`2026-10-21-sort-order-design.md`（主菜单排序）。

## 1. 目标

浏览方式可选「分页」（现状，默认）或「滚动」：滚动时各页上下排开，用滚轮或触控板上下滚动；拖动、多选、键盘、右键、整理布局照常按页工作。

### 不在本期

窗口模式（5c-2）；所有应用连成一串的滚动。

## 2. 参考依据

LaunchOS「浏览样式」：分页 / 滚动。

## 3. 交互规则

### 3.1 入口

主菜单「浏览方式 ▸ 分页 / 滚动」（打勾单选），选择立即生效并保存；搜索时也可切换。

### 3.2 显示

- 搜索框下方到屏幕底部为滚动区域，各页依次上下排列，页与页之间留间隔并画一条淡分隔线；不显示页码点。
- 每页按自身行数排布，行距用紧凑行距（与文件夹相同），列数与图标大小同分页。
- 搜索结果同样按页上下排列。

### 3.3 操作

- 滚轮与触控板上下滚动内容；空白处拖动不再翻页。⌘← / ⌘→ 滚到上一页 / 下一页的顶部；需要回第一页时滚回顶部。
- 点击、右键、长按、框选、卸载的 ×、拖动落点都按指针所在的页计算。框选可跨页。
- 拖动图标靠近滚动区上下边缘时自动滚动，越靠近越快；不再有左右边缘翻页。拖到最后一页末尾之后照常出现新页。
- 键盘：左右与分页相同；↓ 在一页最后一行时进入下一页同一列，↑ 在第一行时进入上一页最后一行同一列；选中项所在页滚到可见。
- 当前页：仍有部分可见时保持不变；完全滚出可视区后换成最上面可见的页，并清掉键盘选中。全选、整理布局的「当前页」、移动到页等按当前页。
- 打开文件夹、搜索、排序、行列数、隐藏等行为不变。

## 4. 组件

| 组件 | 位置 | 职责 |
| --- | --- | --- |
| `BrowsingStyle` / `LauncherSettings` | LaunchApp | 分页、滚动，持久化 |
| `ItemMenu` | 扩展 | 主菜单「浏览方式」子菜单 |
| `GridNavigator` | 扩展 | 可选跨页上下移动 |
| `GridHitTester` | 扩展 | 可关闭左右边缘翻页区 |
| `LauncherModel` | 扩展 | 浏览方式；各页位置；按指针所在页命中；当前页随滚动更新；滚动请求（到某页、拖动时的自动滚动） |
| `LauncherView` | 扩展 | 滚动布局、上报各页位置、执行滚动请求 |
| `LauncherInputMonitor` / `LaunchApp` | 扩展 | 滚动时滚轮事件交给滚动视图 |

## 5. 测试与验证

- `GridNavigator`：跨页上下移动与列号钳制；不跨页时与现状一致。
- `GridHitTester`：关闭边缘后两侧为普通格子。
- `LauncherModel`：滚动时按指针所在页给出按住、右键、框选（跨页）、拖动落点；当前页随滚动保持与切换；边缘自动滚动请求；⌘→ 与选中换页时的滚动请求；分页时与现状一致。
- 设置与菜单：默认分页、持久化、子菜单打勾与命令。
- 目标机 e2e：切到滚动后页码点消失、滚轮下滚能看到第 2 页的图标；滚动时右键第 2 页图标弹出该应用的菜单；把第 1 页图标拖到第 2 页（拖到下边缘自动滚动）后布局正确、⌘Z 复原；键盘 ↓ 跨页；切回分页恢复。只跑本期与拖动相关的 e2e。备份并还原布局与设置。
