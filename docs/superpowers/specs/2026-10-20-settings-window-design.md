# 第 5a 期：设置窗口与显示设置 设计

日期：2026-10-20。状态：设计已确认，待编写实施计划。前置：`2026-10-20-context-menu-hide-design.md`（4c）。

## 1. 目标

提供设置窗口，集中管理开机启动、唤起快捷键、菜单栏图标、重新打开时的页面、背景与暗度、隐藏图标名称、隐藏的应用及其搜索可见性；启动器搜索框右侧的「…」与空白处右键打开主菜单。

### 不在本期

行列数（单独一期）；排序方式与整理布局（5b）；浏览样式与窗口模式（5c）；来源目录、布局导出导入（5d）；显示器选择、程序坞图标。

## 2. 参考依据

- LaunchOS 中文本地化（只读）：设置分「通用」「外观」等；「开机自启动」「快捷键」「显示菜单栏图标」「重新打开 LaunchOS 时，可返回首页或延续上次浏览位置」；「背景」：「系统壁纸」「模糊壁纸」「玻璃材质」；「隐藏名称」；「隐藏的应用」「在搜索结果中显示隐藏应用」；「点击搜索栏右侧的 … 按钮，或右键任意空白位置打开主菜单」。
- 本机三块屏幕均为静态 heic 壁纸，`NSWorkspace.desktopImageURL(for:)` 可读出并加载。

## 3. 交互规则

### 3.1 打开设置

- 入口：菜单栏菜单「设置…」（⌘,）；启动器搜索框右侧「…」按钮与空白处右键（或 ⌃ 单击）弹出的主菜单中的「设置…」；启动器打开时按 ⌘,。
- 打开时启动器先关闭，设置窗口显示在鼠标所在屏幕中央；普通窗口，可切走，再次打开时前置已有窗口。
- 关闭菜单栏图标后仍可通过快捷键唤起启动器，再从主菜单进入设置。

### 3.2 设置内容

| 页 | 项目 | 默认 |
| --- | --- | --- |
| 通用 | 开机启动（沿用现有登录项服务，不可用时置灰并说明需安装到 ~/Applications） | 现状 |
| 通用 | 唤起快捷键：点击录制新组合；与 LaunchOS 冲突时显示提示 | ⌥Space |
| 通用 | 显示菜单栏图标 | 开 |
| 通用 | 重新打开时：「停在上次的位置」/「回到第一页」 | 停在上次的位置 |
| 外观 | 背景：玻璃材质 / 模糊壁纸 / 系统壁纸 | 玻璃材质 |
| 外观 | 暗度滑块 0%～80% | 47% |
| 外观 | 隐藏图标名称 | 关 |
| 应用 | 在搜索结果中显示隐藏应用 | 关 |
| 应用 | 隐藏的应用列表：图标、名称、「取消隐藏」；末尾「全部取消隐藏」；为空时显示「没有隐藏的应用」 | — |

### 3.3 效果

- 背景：
  - 玻璃材质为现有效果（系统材质 + 暗度层）。
  - 系统壁纸与模糊壁纸使用启动器所在屏幕的桌面壁纸，按壁纸的缩放与裁剪设置铺满，模糊壁纸再加模糊，上面叠暗度层。
  - 读不到壁纸图片时退回玻璃材质。
- 隐藏名称：主网格、文件夹、拖动卡片都不显示应用与文件夹名称；网格位置与大小不变；打开的文件夹标题照常显示。
- 搜索显示隐藏应用：开启后隐藏应用出现在搜索结果中，半透明显示，可正常启动；其右键菜单的「隐藏」换成「取消隐藏」。
- 主菜单：本期只有「设置…」，第 5b 期加入排序与整理。
- 设置立即保存；外观类设置在下次打开启动器时生效；菜单栏图标立即显示或隐藏。
- 菜单栏「隐藏的应用」子菜单保留。

## 4. 组件

| 组件 | 位置 | 职责 |
| --- | --- | --- |
| `LauncherSettings` | LaunchApp（新增） | `@Observable` 设置对象，读写注入的 `UserDefaults`：重新打开行为、背景、暗度、隐藏名称、搜索显示隐藏应用、显示菜单栏图标 |
| `SettingsWindowController` | LaunchApp（新增） | 持有设置窗口（`NSWindow` + `NSHostingView`），打开时关闭启动器、激活应用并居中 |
| `SettingsView` | LaunchApp（新增） | 三页表单；快捷键用 `KeyboardShortcuts.Recorder`；隐藏应用列表观察模型 |
| `WallpaperProvider` | LaunchApp（新增） | 读取屏幕壁纸地址与缩放选项，按地址缓存 `NSImage`；失败返回空 |
| `LauncherModel` | 扩展 | 隐藏应用改为应用列表；搜索按设置包含隐藏应用并可查询是否隐藏；重新打开回第一页；当前壁纸；空白处主菜单 |
| `ItemMenu` | 扩展 | 主菜单「设置…」；隐藏应用显示「取消隐藏」 |
| `ItemDragController` | 扩展 | 空白处右键/⌃ 单击弹出主菜单；提供在鼠标处弹出主菜单 |
| `KeyCommandMapper` / `LauncherController` | 扩展 | ⌘, → 打开设置 |
| `LauncherView` | 扩展 | 背景、暗度、隐藏名称、隐藏应用半透明、「…」按钮 |
| `StatusItemController` | 扩展 | 「设置…」菜单项；菜单栏图标显隐 |
| `ScreenPresenter` | 扩展 | 显示启动器时告知目标屏幕 |

- 设置窗口直接修改 `LauncherSettings`，属性变化即写入 UserDefaults；启动器视图读取设置绘制；LaunchApp 观察「显示菜单栏图标」切换状态栏图标。
- 「取消隐藏」（右键菜单、设置页、菜单栏）都调用 `LayoutCoordinator.unhide`，进入撤销栈。

## 5. 测试与验证

自动化（XCTest）：

- `LauncherSettings`：默认值、修改后用同一存储域新建实例能读回。
- `WallpaperProvider`：读取临时目录中的图片、文件不存在时返回空、同一地址命中缓存。
- `LauncherModel`：重新打开回第一页与停在原页；搜索包含隐藏应用与标记；隐藏应用菜单为「取消隐藏」；空白处给出主菜单。
- `ItemMenu`：主菜单与「取消隐藏」项；`KeyCommandMapper`：⌘, 映射。

目标机验证：

- 离屏渲染（`NSView.cacheDisplay`）核对三种背景、暗度与隐藏名称。
- CGEvent 端到端：从「…」、空白处右键、菜单栏打开设置窗口；切换隐藏名称、回到第一页、背景等，确认写入设置并在下次打开时生效；设置页取消隐藏。
- e2e 前导出 Launch 的设置域并备份布局，结束后原样导入设置、还原布局并核对哈希。
- 快捷键录制会修改全局快捷键，可能与 LaunchOS 冲突，由用户手动验证。
- 完成后同步 README、架构文档与 `docs/manual-verification.md`。
