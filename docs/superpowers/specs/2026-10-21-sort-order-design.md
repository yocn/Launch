# 第 5b-2 期：排序方式 设计

日期：2026-10-21。状态：设计已确认。前置：`2026-10-21-arrange-layout-design.md`（5b-1）。

## 1. 目标

主菜单「排序方式」：自定义、名称、添加日期、上次使用；升序或降序；可同时排序文件夹内应用；文件夹位置可选与应用混排、在其他应用前或后。

### 不在本期

按类型自动分组（5b-3）；把排序结果写入自定义布局。

## 2. 参考依据

- LaunchOS：排序方式「自定义 / 名称 / 添加日期 / 上次使用」、「升序 / 降序」、「同时排序文件夹内应用」、「文件夹位置：与应用混排 / 其他应用前 / 其他应用后」；「仅在自定义排序模式下可以拖拽调整顺序。」
- 本机：系统按 zh_CN 排序时中文名全部排在英文名前；添加日期用文件系统的「添加日期」（与访达一致，Spotlight 对系统应用没有这一项）；上次使用读 Spotlight 的 `kMDItemLastUsedDate`，从未打开过的应用没有记录。

## 3. 交互规则

### 3.1 入口

主菜单（「…」、空白处右键或 ⌃ 单击）：「全选」「整理布局…」「排序方式 ▸」、分隔线、「设置…」。

「排序方式」子菜单：自定义 / 名称 / 添加日期 / 上次使用（单选打勾）、分隔线、升序 / 降序、分隔线、同时排序文件夹内应用、文件夹位置 ▸（与应用混排 / 其他应用前 / 其他应用后）。自定义时方向、文件夹内排序与文件夹位置置灰。选择立即生效并保存，搜索时也可改（只影响非搜索的网格）。

### 3.2 显示

- 自定义：按保存的布局显示，与现状相同。
- 其他排序：只改显示，不改保存的布局；切回自定义即恢复原排列。
  - 所有可见的应用与文件夹连成一串排序后按每页容量分页；隐藏与未安装的应用不显示。
  - 名称：按拼音与字母混排（中文取拼音，如 App Store、备忘录、地图、iTerm、计算器），相同时按系统比较。
  - 添加日期、上次使用：升序为从早到晚；没有日期的排在最后（不受方向影响），相同按名称。
  - 文件夹的名称按文件夹名，日期取成员中最新的一个。
  - 文件夹位置：混排时与应用一起排序；其他应用前/后时文件夹自成一组排序后放在应用组前/后。
  - 同时排序文件夹内应用：文件夹预览与展开后的顺序按同一规则；关闭时保持文件夹内原顺序。
- 日期数据在启动、应用列表变化和每次关闭启动器后后台刷新，打开期间不重排。

### 3.3 编辑限制

- 非自定义排序时不能拖动、框选、全选与整理布局；从图标上拖动时在启动器底部短暂提示「仅在自定义排序时可以拖动调整顺序」。
- 长按不进入抖动模式；右键菜单的打开、隐藏、取消分组、重命名、移到废纸篓照常可用。

## 4. 组件

| 组件 | 位置 | 职责 |
| --- | --- | --- |
| `DisplaySort`（`SortField`、`FolderPlacement`）、`AppDates` | LaunchCore（新增） | 排序选项与每个应用的日期 |
| `DisplaySorter` | LaunchCore（新增） | 把布局各页按选项排成一串；名称键用拼音 |
| `AppDatesProvider` | LaunchApp（新增） | 后台读取添加日期与上次使用 |
| `LauncherSettings` | 扩展 | 持久化排序选项 |
| `LauncherModel` | 扩展 | `displaySort`、`appDates`；排序后的分页与文件夹；非自定义时禁止拖动；提示文字 |
| `ItemMenu` | 扩展 | 「排序方式」子菜单 |
| `ItemDragController` | 扩展 | 非自定义时从图标拖动给出提示 |
| `LauncherController` | 扩展 | 关闭后回调，用于刷新日期 |
| `LauncherView` | 扩展 | 底部提示 |
| `LaunchApp` | 扩展 | 菜单命令写设置；设置同步到模型；按时机刷新日期 |

## 5. 测试与验证

- `DisplaySorter`：名称拼音混排；日期升降序与缺失排后；文件夹日期取最新成员；三种文件夹位置；文件夹内排序开关；隐藏项不出现。
- `LauncherSettings`：排序选项默认值与持久化。
- `LauncherModel`：非自定义时分页按排序、切回自定义恢复；不能拖动与全选；打开的文件夹按排序；提示显示后自动消失。
- `ItemMenu`：子菜单结构、打勾与置灰、命令。
- 目标机 e2e：各排序下第 1 页顺序符合预期（名称、上次使用对照 Spotlight 读数）、降序、文件夹位置、文件夹内排序；拖动出提示且布局文件不变；切回自定义后与原排列一致；回归第 4b/4c/5a、行列数与整理布局 e2e。备份并还原布局与设置。
