# 第 5b-1 期：整理布局与全选 设计

日期：2026-10-21。状态：设计已确认。前置：`2026-10-21-grid-size-design.md`（行列数）。

## 1. 目标

主菜单加入「全选」与「整理布局…」：整理可填满空位、取消所有分组，范围为当前页、选择的页面或全部页面，一步 ⌘Z 撤销。⌘A 选中当前页全部图标。

### 不在本期

排序方式（名称、添加日期、上次使用）与文件夹位置（5b-2）；按类型自动分组（5b-3）。

## 2. 参考依据

LaunchOS「整理布局」有规则（整理空位、跨页面整理、取消所有分组等）与范围（当前页面、所选页面、全部页面，所选页面可全选、至少选一页），整理前提示会替换当前布局。

本项目的页面中间没有空洞：隐藏与未安装的应用不占位置，可见项总是连续排列，空位只出现在未满页的末尾。因此「整理空位」与「跨页面整理」合并为一个规则「填满空位」。

## 3. 交互规则

### 3.1 入口

- 主菜单（搜索框右侧「…」、空白处右键或 ⌃ 单击）：「全选」「整理布局…」、分隔线、「设置…」。
- 两项都只在搜索框为空、未打开文件夹、布局可编辑时可用，否则置灰。
- ⌘A：满足同样条件时选中当前页全部图标；搜索框有文字时照常全选文字。

### 3.2 全选

选中当前页所有应用与文件夹，之后可用已有的多选操作（拖动、合并、移动到页、隐藏）。Esc 或点空白清空。

### 3.3 整理布局对话框

- 规则（可同时勾选，至少一项）：
  - 填满空位：把范围内的页面连成一串重新排满，去掉排空的页；范围只有一页时不可选。
  - 取消所有分组：范围内的文件夹拆开，与单个「取消分组」一致，成员按文件夹顺序放到所在页末尾。
- 范围：当前页（第 n 页）/ 选择页面 / 全部页面（默认）；选择页面时列出各页勾选框并提供「全选」，至少选一页。
- 按钮：「整理」（规则或范围无效时不可用）与「取消」。说明文字提示可按 ⌘Z 撤销。
- 结果：
  - 填满空位后的页面按顺序放回所选页面原来的位置，多出的页紧跟在最后一个所选页面之后，排空的页去掉；范围外的页不动。
  - 只取消分组时，某页放不下的部分拆成紧随其后的新页，不挤动其他页。
  - 两项同时勾选时先拆文件夹再填满。
  - 隐藏与未安装的应用保持与相邻项的相对顺序。
  - 整个整理是一次编辑，⌘Z 一步撤销；布局没有变化时不记入撤销。

## 4. 组件

| 组件 | 位置 | 职责 |
| --- | --- | --- |
| `LayoutArrangement` / `LayoutEdit.arrange` | LaunchCore | 页面范围与规则；编辑器按规则重排 |
| `ArrangeOptions` | LaunchApp（新增） | 对话框选择状态：规则、范围、所选页；校验与生成 `LayoutArrangement` |
| `ArrangeLayoutDialog` | LaunchApp（新增） | `NSAlert` + 附加视图，显示在启动器之上 |
| `MultiSelection` | 扩展 | 以给定项替换选择 |
| `LauncherModel` | 扩展 | `selectAllOnPage()`；主菜单内容带可用状态 |
| `ItemMenu` | 扩展 | 主菜单「全选」「整理布局…」 |
| `KeyCommandMapper` / `LauncherInputMonitor` / `LauncherController` | 扩展 | ⌘A → 全选 |
| `LaunchApp` | 扩展 | 「整理布局…」弹出对话框并提交编辑 |

## 5. 测试与验证

- `LayoutEditor`：全部页填满（含隐藏项相对顺序、去掉空页）；所选不连续页填满后其他页不动、多出的页紧跟其后；只取消分组时溢出拆成后续页；两项同时；无变化返回原文档。
- `ArrangeOptions`：默认值、范围解析、校验（无规则、无页、单页只填满）。
- `LauncherModel`：全选当前页；条件不满足时不选；主菜单可用状态。
- `ItemMenu`：主菜单项与置灰；`KeyCommandMapper`：⌘A 仅在允许时映射。
- 目标机 e2e：⌘A 与菜单全选；对话框各控件；全部页填满后页数与每页格数符合预期、⌘Z 复原；所选页面整理；取消所有分组后文件夹消失、⌘Z 复原；回归第 4b/4c/5a 期与行列数 e2e。备份并还原布局与设置。
