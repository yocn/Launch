# 第 3 期：键盘与翻页 设计

日期：2026-10-19。状态：设计已确认，待编写实施计划。前两期见 `2026-10-19-resident-launcher-design.md`、`2026-10-19-layout-inheritance-design.md`。

## 1. 目标

按旧 Launchpad 惯例补齐键盘选择、Return 启动、多种翻页方式与翻页动画；文件夹支持键盘导航、超过 35 个成员时分页，并从格子位置放大展开。

### 不在本期

拖拽、重命名、隐藏（第 4 期）；快捷键录制与背景设置（第 5 期）。

## 2. 交互规则

### 2.1 主网格选择

- 唤起时无选中项，打字即搜索。
- 首次按方向键选中当前页第一个格子。
- ←/→ 按阅读顺序移动，行尾换行；页末 → 到下一页第一个，页首 ← 到上一页最后一个；首页首格、末页末格停住。
- ↑/↓ 同列移动；顶行、底行停住，不跨页；下一行不满时落到该行最后一个。
- Return：应用 → 启动；文件夹 → 打开并选中第一个成员；空位或无选中 → 无动作。
- 选中高亮为格子圆角底，白色 26% 不透明度（悬停为 15%）；悬停不改变选中项。

### 2.2 搜索

- 搜索词非空时自动选中第一个结果；方向键在结果中移动，不移动输入框光标。
- 搜索词清空时清除选中。

### 2.3 输入法

输入框存在未上屏的组字（`NSTextView.hasMarkedText()`）时，方向键与 Return 不拦截，交给输入法。

### 2.4 翻页

- ⌘← / ⌘→：上一页 / 下一页。
- 鼠标拖动（参考 LaunchOS 录屏）：网格区域内（含图标与空白）按住左右拖动，页面按水平位移一比一跟随；移动不足 6pt 视为点击。松手时以含速度的预测位移判断：超过页宽 30% 翻到相邻页，否则吸附回原页，动画约 0.3 秒。第一页右拖、最后一页左拖按位移的 30% 阻尼偏移并回弹。拖动过的这次按下不会启动或打开松手处的格子。主网格、搜索结果、文件夹分页均适用。
- 触控板（有手势阶段的精确滚动）：起手位移以水平为主时与鼠标拖动相同，跟手并按预测位移判断翻页或回弹；以竖直为主时每次手势最多翻一页，累计位移超过 40pt 触发。惯性阶段忽略；手势开始时重置。
- 鼠标滚轮（非精确滚动）：每 0.35 秒最多翻一页。
- 方向跟随系统滚动设置：内容向左或向上移动（delta < 0）为下一页，反之上一页。
- 分页圆点保持可点击。
- 翻页动画：所有页横向并排，按页号平移，约 0.3 秒 easeOut。
- 经 ⌘、滚动、圆点翻页后清除选中；方向键越界翻页时选中项随之落到新页。

### 2.5 文件夹

- 打开期间方向键、Return、翻页作用于文件夹内，规则同 2.1、2.4。
- 每页 35 个成员（7×5）；多于 35 时面板下方显示文件夹分页圆点；取代第 2 期「面板内滚动」。
- 鼠标点开不预选成员；Return 打开选中第一个成员。
- Esc 关闭文件夹后选中项落在该文件夹格子上（Esc 分层不变：文件夹 → 搜索词 → 启动器）。
- 展开动画：整个展开视图（名称 + 面板）从文件夹格子的位置与大小缩放平移到最终位置，同时淡入；关闭时反向。

## 3. 组件

| 组件 | 新增/修改 | 职责 |
| --- | --- | --- |
| `GridNavigator` | 新增 | 每页项数 + 当前页 + 当前位置 + 方向 → 新位置；主网格与文件夹共用 |
| `KeyCommandMapper` | 新增 | 键码 + 修饰键 + 是否组字 → 命令（移动、确认、上一页、下一页）或放行 |
| `PageScrollInterpreter` | 新增 | 滚动样本序列 → 翻页方向 |
| `LauncherInputMonitor` | 新增 | 本地监听 `keyDown`、`scrollWheel`，只处理启动器面板事件；识别为命令的按键吞掉 |
| `LauncherModel` | 修改 | 主网格选中、文件夹页与选中；移动、确认、翻页；选中重置规则 |
| `LauncherController` | 修改 | `handle(_:)` 统一处理命令；确认落在应用上走启动流程 |
| `ScreenPresenter` | 修改 | 提供「是否启动器面板」「输入框是否组字」查询 |
| `LauncherView` | 修改 | 所有页横向并排平移；选中高亮；记录文件夹格子位置；文件夹分页与放大展开 |

命令类型：

```swift
enum MoveDirection { case left, right, up, down }
enum LauncherCommand: Equatable { case move(MoveDirection), activate, nextPage, previousPage }
```

键码：← 123、→ 124、↓ 125、↑ 126、Return 36、小键盘 Enter 76。判断修饰键时只看 ⌘ ⌥ ⌃ ⇧（方向键事件自带数字键盘与功能键标志）。

## 4. 选中状态规则（`LauncherModel`）

| 事件 | 主网格选中 | 文件夹 |
| --- | --- | --- |
| 唤起 | 清除 | 关闭 |
| 搜索词变为非空 | 结果非空时选第一个，否则清除 | 关闭 |
| 搜索词清空 | 清除 | 不变 |
| ⌘/滚动/圆点翻页 | 清除 | 关闭 |
| 鼠标点开文件夹 | 不变 | 打开，第 1 页，无选中 |
| Return 打开文件夹 | 不变 | 打开，第 1 页，选中第一个成员 |
| Esc 关闭文件夹 | 落到该文件夹格子 | 关闭 |
| 布局或应用列表变化 | 超出范围时收回到最后一项，无项时清除 | 文件夹消失则关闭；页号收回范围内 |

## 5. 测试与验证

- 单测：`GridNavigator`（四向、边界、跨页、不满行、空）；`KeyCommandMapper`（附带标志的方向键、Return/Enter、⌘←/→、组字放行、其他修饰键放行）；`PageScrollInterpreter`（一次手势一页、阈值、惯性忽略、重置、滚轮冷却、方向）；`LauncherModel`（2.1–2.5 与第 4 节）；`LauncherController`（命令分发与启动）。
- 离线渲染：选中高亮；构造 40 个成员的文件夹验证分页圆点。
- 端到端（模拟键鼠）：方向键 + Return 启动、搜索后 Return 启动、⌘→ 翻页、滚轮翻页、Return 打开文件夹。
- 需用户目测：翻页与展开动画、拼音组字时方向键交给输入法。
