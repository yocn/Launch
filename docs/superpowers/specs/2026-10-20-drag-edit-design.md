# 第 4a 期：拖拽重排与文件夹编辑 设计

日期：2026-10-20。状态：设计已确认，待编写实施计划。前几期见 `2026-10-19-*-design.md`。

## 1. 目标

在主网格和文件夹里直接拖动图标调整布局：页内与跨页移动、拖到图标上建文件夹、放进或拖出文件夹、文件夹内排序、文件夹改名；编辑即时保存并支持 ⌘Z 撤销。

### 不在本期

多选与批量操作（4b）；右键菜单、隐藏应用（4c）；排序方式、行列、来源目录等设置（第 5 期）；拖到 Dock 或 Finder。

## 2. 参考依据

- LaunchOS 录屏（2026-10-20 11.51.27）：鼠标一动图标即被拿起，原格子空出；拖到应用中心停留约 0.1s 后目标背后出现文件夹底板；松手后在目标位置生成「未命名」文件夹，成员顺序为目标在前、被拖项在后，后续放入的接在末尾；拖走后后续图标整体前移补位，跨行沿斜线移动，页面始终紧凑。
- LaunchOS 二进制符号（只读）：图标网格作为拖拽源发起 `NSDraggingSession`（`setDraggingFrame:contents:`、`draggingSession:movedToPoint:`、`draggingSession:endedAtPoint:operation:`），有 `DragEdgeZone`、`edgeHoverThreshold`、`folderMergeScale`、`detachedSourceFolder`；抖动模式仅用于卸载。
- 录屏未覆盖的插入让位、边缘翻页、拖出文件夹，按系统 Launchpad 惯例（用户确认）。

## 3. 交互规则

### 3.1 拿起

- 在图标上按下并移动超过 4pt 即发起拖拽；拖拽图像为图标加名称的快照，原格子空出。
- 只有在空白处按下才是翻页拖动（**改变现有行为**：此前从图标上拖动也会翻页）；按下不动松开仍为点击启动；触控板双指滑动不变。
- 搜索中、布局文件只读时不发起拖拽。

### 3.2 插入与让位

- 指针在某图标左侧边缘或两格之间 → 插到该图标前；右侧边缘 → 插到其后；最后一项之后的空白 → 插到页末。
- 指针在同一插入位置停留约 0.15s 后，其余图标让出空位、原空位同时合上（0.25s 缓出）。

### 3.3 合并

- 指针进入应用图标中心区停留约 0.1s → 目标背后出现文件夹底板，此时不让位。
- 应用 → 应用：在目标位置新建文件夹「未命名」，成员为 [目标, 被拖项]。
- 应用 → 文件夹：放到文件夹末尾。
- 被拖的是文件夹时没有合并目标，只能插入。

### 3.4 边缘翻页

- 指针在网格左右边缘区停留 0.5s 翻一页，继续停留每 0.8s 再翻一页，沿用逐帧翻页动画。
- 最后一页右边缘停留会临时出现一个空白页；放在那里成为新页，否则丢弃。

### 3.5 文件夹内

- 打开的文件夹里拖动成员为文件夹内排序（只插入，不合并）。
- 拖到文件夹面板外停留 0.3s：文件夹关闭，图标回到主网格继续拖，可插入或合并到其他项。
- 成员只剩 1 个时文件夹解散，剩下的应用占据文件夹原位置。

### 3.6 放下与取消

- 放下：执行编辑并保存；图标从松手位置约 0.2s 落到目标格；位置未变时不产生编辑。
- 拖出面板外松开或按 Esc：取消，系统把拖拽图像飞回原位，排列复原。拖到面板外不接受放置，避免把应用拖进 Finder 被复制。

### 3.7 文件夹改名

- 点击打开文件夹的标题进入编辑，文字全选；Return 或点击别处确认，Esc 取消；空名恢复为「未命名」。
- 改名期间方向键、Return、Esc 交给输入框。

### 3.8 撤销与其他

- 搜索框为空且不在改名时，⌘Z 撤销上一次布局编辑（最多 20 步，退出应用后清空）；撤销后当前打开的文件夹若已不存在则关闭。
- 拖动途中到达的目录或布局变化暂存，放下后再刷新。
- 编辑完成后清空键盘选中项。

## 4. 组件

| 组件 | 位置 | 职责 |
| --- | --- | --- |
| `LayoutEditor` | LaunchCore | 纯函数：`apply(编辑, 文档, 目录, 容量) -> 文档`，规则见第 5 节 |
| `GridHitTester` | LaunchApp | 用 `LauncherHomeLayout` 的格子几何把面板坐标换算成页、格子与命中类型（合并、前插、后插、页末、边缘区） |
| `DragSession` | LaunchApp | 被拖项、来源（主网格或文件夹）、命中目标与悬停计时（注入时钟），生成预览排列 |
| `ItemDragController` | LaunchApp（AppKit） | 在 `LauncherHostingView` 上发起 `NSDraggingSession`，作为拖拽源接收 `movedTo`/`endedAt` 并交给模型；面板外操作返回空；取消时 `animatesToStartingPositionsOnCancelOrFail` |
| `LauncherModel` | 扩展 | 持有 `DragSession`，对外暴露预览排列与合并目标；`onEdit` 回调提交编辑 |
| `LayoutCoordinator` | 扩展 | `apply(_:)`、`undo()`，维护撤销栈 |
| `KeyCommandMapper` | 扩展 | ⌘Z → `.undoLayoutEdit`（搜索为空、未在改名时） |

数据流：手势 → `ItemDragController` → `LauncherModel`/`DragSession` → 放下时 `onEdit(LayoutEdit)` → `LayoutCoordinator.apply` → `LayoutEditor` → `LayoutStore.save` → 发布 → `LauncherModel.updateLayout`。

## 5. `LayoutEditor` 规则

编辑类型：

- `move(项, 到目标)`：主网格项移动；目标为 `insert(可见页, 在某项之前 / 页末)`、`newPage`、`merge(某项)`。
- `moveOutOfFolder(应用, 文件夹, 到目标)`：拖出文件夹到主网格目标。
- `reorderInFolder(文件夹, 应用, 在某成员之前 / 末尾)`。
- `renameFolder(文件夹, 名字)`。

规则：

- 按身份定位：应用用 `stableKey`（经目录解析），文件夹用 `id`；未安装应用留在原槽位，不显示，不计入容量。
- 插入后某页可见项超过容量：最后一项挤到下一页开头，连锁进行；最后一页满则新建页。
- 编辑涉及的页去掉 `.empty`；空页删除；首次编辑前拆分可见项超过容量的旧页，使可见页与文档页一一对应。
- 新文件夹 `id` 为 `folder-<UUID>`、名字「未命名」；成员（含未安装）只剩 1 个时解散；文件夹并入文件夹视为无效，原样返回。
- 结果与原文档相同时原样返回，调用方据此跳过保存与撤销记录。

`LayoutCoordinator`：只读模式忽略编辑；有变化时旧文档入撤销栈（上限 20）后保存发布；`undo()` 弹栈保存发布；重新导入或从备份恢复后清空撤销栈。

## 6. 测试与验证

自动化（XCTest）：

- `LayoutEditorTests`：页内前插、后插、页末；跨页；多页连锁挤出；新建页；应用合并建文件夹（位置、成员顺序、名字）；放入文件夹；文件夹不能合并；文件夹内排序；拖出文件夹；剩 1 个解散；改名含空名；未安装应用保持位置且不占容量；拆分超量旧页；删除空页；无变化原样返回。
- `GridHitTester`：中心区合并、边缘前插/后插、页末、边缘翻页区。
- `DragSession`：注入时钟覆盖 0.1s/0.15s/0.3s/0.5s/0.8s 阈值、预览排列、取消复原。
- `LayoutCoordinator`：应用编辑、撤销、20 步上限、只读忽略、导入后清空。
- `KeyCommandMapper`：⌘Z 的映射条件。

实现与目标机验证：

- 第一步做最小验证：从 SwiftUI 网格发起 `NSDraggingSession`，确认 SwiftUI 手势、按钮按下态、翻页拖动无残留。
- CGEvent 端到端：页内重排、拖到应用建文件夹、拖入文件夹、边缘翻页、拖出文件夹、Esc 取消、⌘Z；通过 `layout.json` 与辅助功能树核对。
