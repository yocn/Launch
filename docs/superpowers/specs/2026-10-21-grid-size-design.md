# 行列数设置 设计

日期：2026-10-21。状态：设计已确认。前置：`2026-10-20-settings-window-design.md`（5a）。

## 1. 目标

在设置的「外观」页加入「网格」：可调列数与行数，主网格、文件夹、拖动、键盘导航、布局编辑都按新的行列工作。

### 不在本期

图标大小单独调节（LaunchOS 的 iconScale）；整理空位、跨页整理（5b）。

## 2. 参考依据

LaunchOS 有 `columns`、`rows`、`iconScale` 设置；「整理空位」说明为「按当前行列布局把应用前移填补空位」，即改行列本身不自动前移。

## 3. 交互规则

- 范围：列 4～10，行 3～8；默认 7 列 × 5 行。设置立即保存，下次打开启动器生效。
- 尺寸：
  - 网格区域高度、搜索框、页码点位置不变。
  - 放得下时图标保持默认大小，多出的宽度与高度均分到间距（行少时行距变大）。
  - 放不下时（行或列多于默认）整体等比缩小图标、名称与格子，列间距不小于默认行距。
- 文件夹面板：列数随网格；行数上限为网格行数；行距保持紧凑（默认行距随图标缩放），不随主网格均分。
- 布局：
  - 改小：每页超出的部分在显示时拆成紧随其后的新页，其他页不受影响。
  - 改大：各页内容不动，末尾留空位，不自动前移。
  - 下次编辑布局时按当时的行列写入；写入前改回原行列可完全复原，写入后再改大，拆出的页不会自动合并。
- 搜索结果、文件夹分页、新安装应用追加到末页，都按新的每页容量。

## 4. 组件

| 组件 | 位置 | 职责 |
| --- | --- | --- |
| `GridSize` | LaunchApp（新增） | 列数、行数、容量，按范围钳制；默认 7×5 |
| `LauncherSettings` | 扩展 | `gridColumns`、`gridRows` 读写 UserDefaults，`grid` |
| `LauncherHomeLayout` | 扩展 | 持有 `grid`；放不下时的缩放系数；行距均分；文件夹紧凑行距与行数 |
| `GridHitTester` | 扩展 | 列数、行数取自布局；文件夹可指定行距 |
| `LauncherModel` | 扩展 | `grid` 与 `updateGrid(_:)`；分页、键盘导航、拖动容量按 `grid` |
| `LayoutCoordinator` | 扩展 | 每页容量可更新，编辑、导入、追加新应用按当前容量 |
| `SettingsView` | 扩展 | 外观页「网格」：列数、行数步进器 |
| `LaunchApp` | 扩展 | 设置变化时同步到模型与布局协调器 |
| `LauncherView` | 扩展 | 按 `grid` 构建布局；文件夹网格用紧凑行距 |

## 5. 测试与验证

- `GridSize`：钳制范围、容量。
- `LauncherHomeLayout`：默认 7×5 与现状完全一致；各行列组合在各屏幕上网格放得下、列间距为正；行少时图标不变、行距均分；行列多时图标缩小；文件夹行数上限与紧凑行距。
- `GridHitTester`：非默认列数下的格子位置与命中。
- `LauncherModel`：按新容量分页；改小时超出部分拆成后续页；键盘导航按新列数。
- `LayoutCoordinator`：更新容量后编辑按新容量写入。
- `LauncherSettings`：默认值与持久化。
- 目标机：e2e 改为 5×4 后打开，核对每页格数与位置、拖动与键盘；改回 7×5 后布局按字节不变（未编辑时）；回归第 4b/4c/5a 期 e2e。备份并还原布局与设置。
