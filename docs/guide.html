Launch 使用指南

Launch 是一个原生的 macOS 启动台：按一下快捷键，所有应用铺满屏幕，搜索、翻页、拖动整理都在这里完成。

快速上手

1. 打开按 ⌥ 空格，或点菜单栏里的 Launch 图标。
2. 找应用直接打字搜索，支持拼音和首字母，↩ 打开第一个结果。
3. 整理按住图标拖动排序，拖到另一个应用上合成文件夹，⌘ Z 撤销。
4. 个性化点搜索框右侧的「…」→「设置…」，或按 ⌘ ,。

第一次启动时，Launch 会询问是否导入系统启动台（Launchpad）原有的页面和文件夹；导入只读取，不会改动系统数据。

打开与关闭

打开启动器

方式说明
快捷键默认 ⌥ 空格，可在「设置 → 通用 → 唤起快捷键」里修改。再按一次关闭。
菜单栏图标左键直接打开；右键或按住 ⌃ 单击弹出菜单（导入布局、隐藏的应用、设置、退出等）。
触发角指针移到屏幕的某个角时打开或关闭。默认关闭，在「设置 → 通用 → 触发角」里选择角落；与系统或 LaunchOS 的触发角冲突时会提示。
F4 键开启「设置 → 通用 → 系统 F4 键」后，按 F4（或启动台键）打开。需要辅助功能权限。
触控板捏合在「设置 → 通用 → 触控板」里选三指、四指或五指、五指捏合。需要辅助功能权限。
程序坞 / ⌘Tab开启「设置 → 外观 → 显示在 ⌘Tab／程序坞」后，可以像普通应用一样点程序坞图标或用 ⌘ Tab 切回来。

关闭启动器

  • 再按一次唤起快捷键；设置窗口浮在启动器上时会一起关掉。
  • 按 esc：先关掉打开的文件夹、清空搜索词，再按一次关闭启动器。
  • 点空白处；打开应用后、切到其他应用时也会自动关闭。

启动器出现在哪块屏幕可以在「设置 → 通用 → 显示在」里选择：鼠标所在屏幕、当前激活屏幕、程序坞所在屏幕或主屏幕。

网址与快捷指令

  • 设置 →「条目」→「添加网址…」填写名称与 HTTP(S) 网址，可选择自己的图标；默认先进入搜索目录，不占网格。
  • 在网格空白处右键「添加网址…」，保存后固定到所点页面。搜索结果或条目设置菜单的「添加到网格」也可手动固定。
  • 快捷指令自动只读发现，可搜索后运行，或右键固定；设置中可刷新清单。更换图标和名称只影响 Launch，不修改系统快捷指令。
  • 左下角地球表示网址，叠层表示快捷指令。固定后可像应用一样拖动、分组和隐藏；「从网格移除」只移除固定位置，网址「删除网址入口」只删 Launch 记录，不动浏览器、文件或系统指令。
  • 已删除或未同步的固定快捷指令保留灰色入口，不能执行。同一指令运行期间不会重复启动；失败不会自动重试。超时不代表系统工作流已终止，请先检查状态。
  • 网站图标仅在新增、修改网址或手动刷新时从该网站获取，失败用首字图标。网址、固定位置与自定义图片都包含在 v2 布局备份中。

搜索

  • 打开启动器后直接打字即可，不需要先点搜索框。
  • 支持中文名、拼音全拼、首字母和混拼，例如 bwl、beiwanglu 都能找到「备忘录」；多音字按词读音，如「音乐」用 yinyue / yy。
  • 也能用英文名搜，例如 settings 找到「系统设置」。
  • 结果按「名称开头 → 拼音从头匹配 → 其他位置匹配」排序，并自动选中第一个，按 ↩ 打开。
  • 用中文输入法组字时，方向键和回车交给输入法，不会误触发启动器操作。
  • 按 esc 或点搜索框里的 × 清空，回到网格。

翻页与浏览

分页（默认）

  • 滚动鼠标滚轮、在触控板上左右轻扫，或在空白处按住拖动翻页。
  • ⌘ ← / ⌘ → 切到上一页 / 下一页，也可以直接点底部的页码点。

滚动与窗口

  • 主菜单「浏览方式 → 滚动」：各页上下排开，用滚轮或触控板连续浏览。
  • 主菜单「显示方式 → 窗口」：在屏幕中央显示一个圆角窗口，窗口外不压暗，点窗口外关闭。

「设置 → 通用 → 回到第一页」可以让启动器关闭一段时间后，下次打开自动回到第一页。

整理图标

拖动

  • 在图标上按住拖动即可调整位置，可以跨页：拖到屏幕左右边缘停一下会自动翻页，拖到最后一页之后会新建一页。
  • 拖到另一个应用上，合并成一个「未命名」文件夹；拖到文件夹上则放进文件夹。
  • 拖动排序只在「排序方式 → 自定义」下可用；按名称、日期等排序时只改变显示，不能拖动。

文件夹

  • 点文件夹打开，点面板外或按 esc 关闭；点标题即可改名。
  • 在文件夹里可以拖动排序，也可以把图标拖出文件夹。
  • 右键文件夹可以重命名、取消分组或隐藏。

整理布局

主菜单「整理布局…」可以一次处理多页：

  • 填满空位：把后面的图标往前补，消除页面里的空格。
  • 取消所有分组：把文件夹里的应用都放回页面。
  • 按类型分组：按 App Store 类别把散落的应用归进文件夹。
  • 范围可选当前页、选择的页面或全部页面，整理完可以用 ⌘ Z 一步撤销。

多选

  • 按住 ⌘ 单击图标逐个选中，或按住 ⌘ 在空白处拖出选框；⌘ A 选中当前页全部。
  • 选中的图标右上角显示蓝色对勾；拖动其中一个，所有选中的会一起移动。
  • 在选中的图标上右键：合并到新文件夹、合并到选中的文件夹、移动到第几页或新页面、隐藏。
  • 按 esc 或点空白处取消选择。

隐藏应用

  • 右键应用或文件夹选「隐藏」，它会从网格里消失，但保留原来的位置。
  • 在「设置 → 应用 → 隐藏的应用」或菜单栏菜单「隐藏的应用」里取消隐藏，会回到原位置。
  • 「设置 → 应用 → 在搜索结果中显示隐藏应用」决定搜索时能否搜到它们。

卸载应用

  • 长按任意图标进入抖动模式（开启「按住 Option 进入卸载模式」后也可以按住 ⌥），可卸载的应用左上角出现 ×；也可以右键选「移到废纸篓…」。
  • 系统应用和需要管理员权限才能删除的应用不显示 ×。
  • 确认窗口会列出应用本体和找到的关联文件（缓存、日志、偏好设置等）。关联文件默认都不勾选，需要你逐项确认；沙盒容器、共享容器等无法确认归属的只展示、不移动。
  • 所有文件只会移到废纸篓，不会直接删除。完成后可以「在访达中显示记录」，按记录里的原路径找回文件。
  • 应用正在运行时，会先请求它正常退出，退出失败则不移动任何文件。

设置

设置窗口有四页。在启动器上打开设置时，设置窗口浮在启动器上方，改动会立即生效；点启动器任意处只关闭设置。

通用

开机启动登录后自动在后台运行（需安装在 ~/Applications）。
唤起快捷键点一下录制框，再按新的组合键。录制时其他应用占用的组合键会录不上，换一个即可。
显示在鼠标所在屏幕 / 当前激活屏幕 / 程序坞所在屏幕 / 主屏幕。
回到第一页从不、5 秒、15 秒、30 秒、1 分钟、5 分钟后，或始终。
按住 Option 进入卸载模式默认开启。
触发角 / 系统 F4 键 / 触控板其他打开方式，见「打开与关闭」。

外观

应用图标三套图标，跟随系统 / 浅色 / 深色；可选择是否显示在 ⌘Tab／程序坞、状态栏。
背景玻璃材质 / 模糊壁纸 / 系统壁纸。
暗度20%～80%，背后是浅色窗口时适当调高，名称更清楚。
隐藏图标名称隐藏后名称的空间让给图标，图标会变大。
显示程序坞打开后底部的程序坞保持可见、可点击，启动器内容避开程序坞。
网格列数 4～10、行数 3～8，默认 7 列 × 5 行；放不下时整体缩小。
图标排列行列较少时，铺满屏幕或集中在中央。
设置窗口玻璃或普通样式；玻璃样式可调不透明度。

应用

应用来源默认扫描「应用程序」等系统目录，可添加自定义目录（含子文件夹），变化后自动刷新。
隐藏的应用查看并取消隐藏；可选是否在搜索结果中显示。

数据

布局备份导出布局到 JSON 文件，或从备份导入。导入前会自动备份当前布局。
诊断导出诊断信息（日志、崩溃报告、设置、布局与系统信息）为 zip，只保存到你选的位置。
Launchpad从系统启动台导入布局，或恢复导入前的布局。

数据与备份

内容位置
布局（页面、文件夹、隐藏状态）~/Library/Application Support/Launch/layout.json
卸载操作记录~/Library/Application Support/Launch/UninstallRecords
运行日志~/Library/Logs/Launch/launch.log
  • 新安装的应用会追加到最后一页；卸载后暂时找不到的应用会保留位置，不会打乱布局。
  • 系统启动台和 LaunchOS 的数据只读取，不会被修改。
