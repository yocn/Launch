# 手动验证记录

每次在目标 Mac 上验证交互后，在对应条目下补充日期、显示器配置、系统状态、执行结果和已知限制。

## 基础命令

    swift build
    swift test
    swift run LaunchApp
    ./scripts/build-app.sh
    LAUNCH_SIGN_IDENTITY="Apple Development: …" ./scripts/build-app.sh --install

- 2026-10-19：开发包的默认应用来源已扩展为用户与系统应用目录；来源路径由自动化测试固定，完整网格视觉回归仍受开发包的 ScreenCaptureKit 取屏错误影响。
