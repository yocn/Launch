# Launch：macOS 应用启动器

目标是制作可日常使用的 LaunchOS 替代品。项目工作目录：`/Users/yocn/launch`。

## 接手入口

1. 阅读 [技术架构与产品约定](docs/architecture.md)，了解已确认需求、职责边界与待验证事项。
2. 阅读 [协作约定](AGENTS.md)。Claude 同时可以从 [CLAUDE.md](CLAUDE.md) 进入。
3. 从架构文档的“建议实施顺序”开始，先检查实际项目状态再继续工作。

## 当前状态（2026-10-19）

- 已观察本机 LaunchOS 主界面、搜索、菜单及部分设置页面，并完成初步架构讨论。
- 已核实开发机为 macOS 26.6.1（25G76），安装 Xcode 27.0（27A266a）。
- 已建立可运行的 Swift Package 原型：扫描用户与系统应用目录，展示分页网格并即时筛选。第 1 期常驻唤起已完成：后台常驻、⌥Space 与菜单栏唤起（菜单栏图标左键直接唤起，右键或 ⌃ 单击弹出菜单）、多屏按主显示器布局等比缩放、目录变化自动刷新、开机启动开关、LaunchOS 快捷键冲突提示。第 2 期布局继承已完成：首次启动预览并只读导入旧 Launchpad 布局（页面、顺序、文件夹），布局保存在 `~/Library/Application Support/Launch/layout.json`，可从菜单栏重新导入或与备份互换恢复；未安装应用保留位置不显示，新应用追加到末尾；文件夹可展开、启动成员、点面板外或 Esc 分层关闭。第 3 期键盘与翻页已完成：方向键选中、Return 启动或打开文件夹、搜索时自动选中第一个结果、⌘←/⌘→ 与滚轮翻页并横向滑动、鼠标拖动与触控板横扫跟手翻页（越界阻尼回弹）、文件夹内键盘导航与分页、文件夹从格子放大展开，拼音组字时按键交给输入法。第 4a 期拖拽重排与文件夹编辑已完成：在图标上直接拖动即可页内或跨页移动（指针停在边缘自动翻页，满页时挤到下一页），拖到应用上合并为「未命名」文件夹，拖入、拖出文件夹及文件夹内排序，点击文件夹标题改名，⌘Z 撤销最近 20 步编辑；从图标上拖动不再翻页，只有空白处拖动翻页。长按图标进入抖动模式（点空白或 Esc 退出），当前用户可直接删除的应用显示 ×，确认后移到废纸篓（运行中的会先请求退出）；系统应用和需要管理员权限的应用不显示 ×。第 4b 期多选已完成：按住 ⌘ 单击或拖出选框选中多个图标，可一起拖动插入或合并，也可右键合并到新文件夹、合并到选中的文件夹、移动到指定页或新页面，每次批量操作可 ⌘Z 撤销。第 4c 期右键菜单与隐藏已完成：右键应用可打开、在访达中显示、显示简介、隐藏、移到废纸篓，右键文件夹可重命名、取消分组、隐藏，多选菜单也能隐藏；隐藏的应用保留原位置，在菜单栏「隐藏的应用」中取消隐藏。第 5a 期设置窗口已完成：从菜单栏、搜索框右侧「…」、空白处右键或 ⌘, 打开设置，可设置开机启动、唤起快捷键、菜单栏图标、重新打开时回第一页、背景（玻璃材质、模糊壁纸、系统壁纸）与暗度、隐藏图标名称、隐藏的应用及其在搜索中的显示。搜索支持全拼、首字母与混拼（多音字按词读音，如「音乐」yinyue/yy）和英文名（如 settings 找到「系统设置」），结果按名称开头、拼音从头匹配、其他匹配的顺序排列。图标在后台读取，读完前显示占位。外观设置可调网格行列（列 4～10、行 3～8，默认 7×5）：行列少时图标不变、间距均分，放不下时整体缩小；改小时超出部分拆成紧随其后的页，改大时各页不动。第 5b-1 期整理布局已完成：主菜单「全选」（⌘A）选中当前页全部图标，「整理布局…」可填满空位、取消所有分组，范围为当前页、选择的页面或全部页面，⌘Z 一步撤销。第 5b-2 期排序方式已完成：主菜单「排序方式」可选自定义、名称（拼音与字母混排）、添加日期、上次使用（Spotlight 记录），升序或降序，可同时排序文件夹内应用、设置文件夹位置；非自定义排序只改显示、不能拖动（拖动时提示），切回自定义恢复原排列。通用设置可选启动器显示在鼠标所在屏幕、当前激活屏幕、程序坞所在屏幕或主屏幕，关闭后隔多久回到第一页（从不到始终七档），按住 Option 进入卸载模式（默认开）。按类型分组、浏览模式、F4/手势等系统入口仍未实现。验证结果与未验证项见 [手动验证记录](docs/manual-verification.md)。
- `./scripts/build-app.sh` 在 `.build/Launch.app` 生成开发用应用包；`./scripts/build-app.sh --install` 以 release 构建并安装到 `~/Applications/Launch.app`，可用环境变量 `LAUNCH_SIGN_IDENTITY` 指定签名证书（固定证书可让开机启动在重装后保持）。
- 旧 Launchpad 数据库位于 `$(getconf DARWIN_USER_DIR)/com.apple.dock.launchpad/db/db`，含 2 个有内容的页面、3 个文件夹、96 个应用；导入规则见 [布局继承设计](docs/superpowers/specs/2026-10-19-layout-inheritance-design.md)。
- `Launch` 是暂用项目名，正式产品名和 Bundle ID 尚未确定。
