# Launch：macOS 应用启动器

目标是制作可日常使用的 LaunchOS 替代品。项目工作目录：`/Users/yocn/launch`。

面向使用者的说明见 [使用指南](docs/guide.html)（网页，可直接用浏览器打开）。

## 接手入口

1. 阅读 [技术架构与产品约定](docs/architecture.md)，了解已确认需求、职责边界与待验证事项。
2. 阅读 [协作约定](AGENTS.md)。Claude 同时可以从 [CLAUDE.md](CLAUDE.md) 进入。
3. 从架构文档的“建议实施顺序”开始，先检查实际项目状态再继续工作。

## 当前状态（2026-10-23）

- 网址与快捷指令首批接入：设置「应用」页的「网址与快捷指令 → 管理…」中，网址可添加/编辑/选图，也可从 Chrome、Safari 书签多选批量添加（空白处右键「从浏览器书签添加…」，只读，Safari 需「完全磁盘访问」）；快捷指令只读发现、搜索并手动固定。网址添加后一律放进网格（空白处右键放到所点页，设置里添加放到最后一页），只有删除、没有「从网格移除」；快捷指令不自动占网格，可手动添加到网格或移除。非应用不提供卸载，左下角地球/叠层角标适配浅深色。布局升级 v2，首次保存前独立保留 `layout.json.v1-backup`；定义与图标随导出/恢复保存。运行同一快捷指令有防重复保护、不自动重试；真实用户指令未自动试运行。访达文件夹与系统设置面板留待后续。技术接口见 [架构第 12 节](docs/architecture.md)。

- 设置 → 通用可独立控制在 ⌘Tab／程序坞、状态栏中显示，立即生效并保存；默认只显示状态栏。两个入口都关闭时仍可用快捷键或在访达重新打开 Launch。
